v9
⓪ 熔炉龙骑改名黑龙，用龙腹横甲。① 锚链铁甲换鹦鹉螺潜艇车体。② 钟表巨像改名齿轮巨像，换机车锅炉车体，锅炉侧面加一列外露的传动齿轮（大小交替、相邻反转），火箱门上一只小齿轮，车腹下的啮合齿轮保留。
③ 齿轮巨像的腿：双胫腿——齿条大腿（胯上小齿轮咬着）+ 膝齿轮 + 两根小腿各一只脚；两只脚步态差半圈（各走半步幅、双倍步频，不打滑），总有一只着地，膝盖永远落在两脚的两个圆的交点上，走起来是一个不断变形的三角。
④ 大本钟的腿：时钟指针腿——胯下一根可伸缩的塔身，下端一只钟面，三根宝玑针像无辐圈车轮一样转着撑地前进（撑地的针一换就一顿）。
⑤ 新增 T3 钢制半人马：马的腿骨结构（后腿膝朝前、跗关节朝后，前腿肘朝后、腕朝前，球节 + 蹄；抬腿时收蹄），同一车速下走得快 1.7 倍、机身起伏约 4～5px。
三种新腿各 4 个方案，见「新腿方案」；上面一览里用每种的 A 方案。现在一共 16 种。

v8：熔炉龙骑的车体和裙板重做，改名铁鳞龙骑——去掉所有透红光，全部是有厚度的物理甲片（上片在下片上投一道阴影、中脊亮线、亮边暗边、粗糙斑点）；三种裙板见「铁鳞龙骑 · 车体裙板」（A 龙脊甲 / B 龙腹横甲 / C 棘背甲）。 腿大幅加粗：大腿三片厚甲（最宽约 15px）、膝上厚膝甲 + 粗角刺、小腿两片甲 + 跗关节粗后刺、粗短跖骨、三根粗弯爪 + 后爪，大腿里的炉膛光也去掉了。

v7
① 步幅加大、步频降低、随车速变：步幅 = 14 + 车速 × 0.12（慢 30 → 17.6px，中 60 → 21px，快 100 → 24px；原来最多 13px）；步态按走过的距离推进（一整步 = 4 × 步幅）， 所以同样车速下步频更低（车速 60 时约 0.7 步/秒，原游戏里约 1.2 步/秒），脚不打滑。抬脚高度和机身起伏也跟步幅变大。顶上加了「车速」切换，画面底下的地面刻度跟着车速往后走——着地的脚应该和刻度一起走、不滑。
② 熔炉龙骑的鳞甲彻底重做：去掉细密小鳞，出 7 种大块方案（见「熔炉龙骑 · 鳞甲裙板」）：B 巨鳞 · A 叠瓦大甲 · C 鳄背脊板 · D 熔岩裂甲 · E 后掠刃鳞 · F 炉门护甲 · G 折翼。都盖住腿根、甲缝透火；上面一览里先用 B 巨鳞。

v6（你对 v5 的四条意见）
① 曲柄步行机的藤蔓：颜色改成压暗的橄榄绿（去掉鲜绿和橙色小花，只留零星米色花点），叶子间距加大一倍，垂藤只留一缕，窗里的盆栽只留三成。
② 锚链铁甲：两根锚链——前面一根短的吊着晃（走路时往后甩），车腹正中一根长的垂到地面、只拖四节；拖地那截跟着前进 / 后退换边（顶上加了「方向」切换，切的时候链子慢慢摆到另一边）。
③ 步行履带：侧裙板从车体中部（y+6）一直垂到 y+28，把腿根整个罩住。
④ 熔炉龙骑：原来的肋骨 / 鳞片车体改成盖住腿根的鱼鳞甲裙板——四排圆鳞上下错开交叠，每片鳞有亮边暗边和中脊，鳞缝就是透出来的炉火（随呼吸明灭、偶尔闪火星），最下一排是带黄铜尖的鳞尖。车体候选 C 也带上了这层裙板。

v5（你对 v4 的六条意见）
① 螳臂步行机换成铁路沙龙车厢车体。
② 水晶宫温室（曲柄步行机）：腿上缠满常春藤（叶子 + 小花），膝上垂下几缕藤蔓随风摆，窗里摆盆栽、檐下垂藤；膝盖改成夸张的高膝，最高点超出车体顶板约 24px（半个底盘高，可以再调）。
③ 汽锤步行机：汽缸更粗，缸底伸出两根并排的活塞杆（中间镂空）、十字头连铁脚；着地的半个周期里连砸三下，每下喷汽、脚边扬尘。
④ 蒸汽圣骑：腿再加粗，纹路改成盔甲：分节大腿甲、一片压一片的分节胫甲（脊线 + 黄铜铆钉）、更大的护膝。
⑤ 步行履带：加一圈一战坦克式侧裙板（六块铆接钢板 + 排泥孔），罩住胯和大腿上部。
⑥ 锚链铁甲：车尾锚链孔拖出一段锚链，垂到地面、在身后拖一截。

v4（你对 v3 的六条意见）
① 仪表步行机取消 → 螳臂步行机：高膝、三角甲板大腿 + 一排倒刺，小腿是越往下越细的粗刀形胫甲，末端就是一根钢尖脚（黄铜箍 + 后刺），只用尖点着地。
② 熔炉龙骑的脚像高跟鞋 → 去掉鞋底，改成分开的弯爪：三根前爪 + 一根后爪，只有爪尖点地，跗关节放低。
③ 蒸汽圣骑换龟足腿：短粗甲板大腿、往下张开的柱状小腿（三排龟甲鳞）、圆护膝 + 小扇翼，脚是圆厚的龟足垫 + 三枚钝甲；风筝盾保留。
④ 天象仪 → 大本钟：车体是垂直式哥特窗格 + 正中大钟面（指针在走）+ 粗挑檐托石；腿是方塔身，膝盖是一座方钟亭，三级台座脚。
⑤ 板簧拖车挤压感：着地承重时膝盖下沉 4.5px，减震弹簧被压短、线圈变密、往两边鼓，板簧被压平；抬脚时弹簧拉回原长、板簧回弓。
⑥ 哥特圣殿 → 哥特教堂：石缝、扶壁柱顶金十字、正中门楼（玫瑰窗 + 尖拱木门）；两个胯位各垂一面深红燕尾旗（金边金十字、随风摆），遮住胯和大腿根。
之前的规则不变：腿加粗、机身按步态起伏、腿按层画（驱动件 → 大腿 → 胯销 → 连杆 → 小腿 → 膝销 → 脚 → 踝销）。T4～T6 车体候选见下方（T6 的 B 换成大本钟）。
