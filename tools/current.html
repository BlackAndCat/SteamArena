这一期三样东西等你挑：① 轻型腿 / 重型腿怎么分；② 走、快跑、下蹲、跳跃四种姿态；③ 腿部件（跳跃件、提速件）各三种方案。腿都是游戏的 js/legs.js 画的——下蹲、空中收腿、快跑的参数已经加进游戏代码（默认画面逐像素没变，等后台规则接上就能用）；躯干用 v4 的零件。游戏画面没动。

要你定的
  1. 轻 / 重怎么分（①）：我的分法是主线六档 = 标准腿，9 种唯一腿分成轻型 5 种、重型 4 种，T3～T6 每档一轻一重。
  2. 四种姿态行不行（②）：快跑有双脚腾空、躯干前倾；下蹲沉 1 个子格；跳跃先蓄力下蹲、空中收腿、地上有影子、落地扬尘。
  3. 跳跃件、提速件各选一个（③）：跳跃件 A 弹簧蹬缸 / B 蒸汽弹射缸 / C 板簧蹬刺；提速件 A 助力活塞 / B 飞轮增速箱 / C 双汽缸增压。
画布都是原生像素 × 2

① 轻型腿 / 重型腿

建议的数值方向（交给后台定，只是方向）：

标准（主线六档）轻型重型
速度基准+10～15%−15%
承重基准−15%+40～60%（能扛重炮）
闪避现在的 0.12更高0
跳跃高度基准×1.5×0.5
下蹲基准基准更稳（散布、后坐再减一档）
走路起伏 / 晃动基准更大更小

② 姿态：走 / 快跑 / 下蹲 / 跳跃

每一行是一类腿 + 一套 v4 躯干：轻型 = 板簧跑刃 + 轻骑，标准 = 掷弹兵 + 突击，重型 = 蒸汽人 + 圣骑。跳跃高度是演示值：轻 1.5 格、标准 1 格、重半格多（规则里按承重余量和腿型算）。

③ 腿部件（侧挂层，挂在近侧腿上）

每种方案装在三条腿上：轻型（板簧跑刃）、标准（掷弹兵）、重型（蒸汽人）。跳跃件放「走 → 蓄力 → 起跳」，提速件放「走 → 快跑」。腿部件跟着腿骨动：画在 legs.js 算出来的大腿 / 小腿上，所以 15 种腿都能直接挂。
