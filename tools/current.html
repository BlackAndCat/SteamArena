v2 → v3 你的意见和我的改法（v1 → v2 的改动：T2 高跷、T5 钟表巨像新脚、T6 詹森 / 缩放仪、7 种腰胯，都保留）：
① T1 撑杆：必须是直的、要有支撑能力。现在是一根笔直的缸 + 杆，两端铰在大腿上段前缘和小腿下段前缘的托耳上，跨在膝弯的内角上——腿一弯它被压短，一伸它把腿顶直，承重靠它（托耳只有半个单位高，缸杆贴着腿，不再是短短一截悬在膝前）。
② 詹森连杆腿重做：去掉了乱的弹簧、铜箍和大托板，只留11 根杆 + 一块脚三角板 + 曲柄，立柱变细，杆分前后两层（前层更亮）、铰点是小黄铜销，一眼能看出是 Strandbeest 的连杆。
③ 缩放仪平行腿 ⇄ 圣堂罩袍对调：缩放仪放进 T4；T6 新画了一条圣堂骑士腿（护膝侧三片向后掠的黄铜羽翼、护胫后缘刀锋尾鳍、又长又尖的铁靴 + 脚跟后刺、大腿甲正中一条发光的能量脉、白布红十字罩袍）。
④ T4 再设计一种骑士风格的腿：锁甲骑士——锁子甲底 + 窄板甲，大圆护膝，鸭嘴靴，锁甲下摆。T4 现在是「蒸汽圣骑 + 锁甲骑士 + 缩放仪」。
⑤ 腰胯按你的分配：T1 蒸汽缸 · T2 差速齿轮 · T3 飞轮调速器 · T4 板簧悬挂 · T5 现役陀螺仪 · T6 万向陀螺；球窝髋给圣堂骑士腿，滚珠座圈给裙甲堡。下面每张卡片都带着分配的腰胯，「腰胯」一节仍可以看全部 8 种。
