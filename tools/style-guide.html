设计支柱

统一靠材质、光源、描边、像素尺度和细节密度；辨识靠剪影和少量语义色。任何模块如果非要看细节才认得出，就算不合格。

统一与辨识分开管

75–85% 是中性冷铁；功能信号只占 15–25%，而且那种颜色全画面只代表这一件事。

形状就是功能

伸出格子的会伤人；空洞 + 人影是驾驶舱；大面积青色是水；会发光的是锅炉；锈钢是撞击件；最暗的是底盘。

整车感

模块嵌在铆接车体框架里，四周留 3px 框架，相邻模块之间打铆钉，只描整车外轮廓。

明度三层

背景压在中低明度、降饱和；载具全明度；炉火、炮口闪光、准星独占最高明度。

一点可爱

钢铁战车里坐着毛茸茸的小炭球：大白眼、小短手，史诗级换上皮飞行帽和黄铜护目镜。

调色板 SA.PAL · 点色块复制色值

一套中性材质 + 语义色，一色一义。精灵只能用这些颜色；中性金属往冷灰蓝拉，暖色只留给语义。

一台车的大致像素占比：冷铁 + 暗铁 ≈ 80%，黄铜点缀，语义色（炉火 / 水 / 玻璃 / 锈）合计不超过四分之一。

风格锚点 4 倍放大 · 看光源、描边、铆钉

每块面按 [描边, 暗面, 固有色, 亮面] 四阶画：上、左沿 1px 亮，下、右沿 1px 暗；描边取材质最暗阶而不是纯黑；铆钉只在边缘，每 4×4 px 最多一个细节。

模块剪影 所有已有专属美术的模块

打开「剪影」看纯黑填充能否认出类别，打开「灰度」看明度是否分层，切到 1× 看实机大小。标签颜色是 UI 里用的类别色（场景里不画角标）。

显示 大小

材料六阶 装饰层只染金属像素

黄铜（原画）→ 熟铁（锻打斑点）→ 钢（冷色高光边）→ 镀镍（镜面条纹）→ 乌兹钢（流水花纹）→ 以太合金（发光纹路）。黄铜、炉火、水、玻璃、皮革不被染色；钢开始火炮和底盘变形，炮口位置不变。

整车与场景 明度三层

背景只用 bg 棕褐色阶、压在中低明度：分层天空 + 抖动过渡、雾中淡日、厂房烟囱剪影、看台人群与彩旗。车用全明度，只有炉火能碰到最亮。切到灰度，三层依然分得开。

界面 css/style.css 的真实组件

铁灰铆钉钢板做底，黄铜 = 可交互 / 已选中。方角、硬边、3px 硬偏移投影，不做模糊和圆角。标题粗黑体加宽字距，带 2px 硬字影。

做 / 不做

做

  • 冷灰蓝的铁占大面积，黄铜只做点缀
  • 靠剪影和比例区分同类型号
  • 1px 材质最暗阶描边，左上光
  • 铆钉只在边缘，低细节密度
  • 炉火是唯一发光（T6 以太纹路例外）
  • 一战 / 维多利亚工业造型，侧视正交剖面
  • 可爱的小炭球驾驶员

不做

  • 整套暖棕、全身黄铜（重蹈 Steamlands 的覆辙）
  • 角标、图标、文字补辨识
  • 纯黑粗描边、抗锯齿、柔和渐变、模糊光晕
  • 满身噪点、铆钉铺满
  • 霓虹、到处发光、洋红出现在场景里
  • 科幻流线、日式机甲尖角、等轴 / 透视 / 3D 感
  • 写实人物、性别特征、血腥

验收清单

  • 剪影测试：纯黑填充能说出类别
  • 灰度测试：背景 / 载具 / 发光物三层分得开
  • 1× 实机：放进 6 层叠放的车里 5 秒内认得出
  • 只用 SA.PAL；语义色 ≤ 25%
  • 光源、描边、铆钉位置符合规则
  • 换 6 阶材料后仍好看，非金属没被染色
  • 武器各阶段炮口位置不变（piv / blen）
  • 在本页和模块精灵表里看过
