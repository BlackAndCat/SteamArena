人物形象 · 碳球 探索 v1 · 2026-09-28

这个世界里的人都是黑色的圆形小碳球：小短手、看不到腿，眼睛 1～3 只。长相都差不多，所以体色（身上反光的色调）和饰品是认人的关键。起点是现在驾驶舱里的蓝灰碳球（第一节）。

同一份角色数据按三种尺寸画：驾驶舱里（半径 3.3，和游戏一样）、场景小人（半径 8，开场和战斗旁白用）、对话头像（半径 19）。全部是程序化像素画，定稿后直接搬进游戏。

请你确认：① 身体用 A 圆煤球 / B 块煤 / C 余烬；② 短手要不要戴白手套；③ 阵容里每个人的造型（可以点名改）；④ 驾驶舱里要不要换成各自的样子（现在所有车的驾驶员都是同一只蓝灰碳球）。

身体 手套 放大

0 · 现在的碳球 游戏里 js/sprites.js 的 pilot()：驾驶舱、联合驾驶舱、史诗起换飞行帽

舷窗里只有 7 像素宽：一个深色圆 + 左上一点反光 + 两只白眼睛（黑眼珠朝前）。驾驶员是蓝灰色调、副驾驶是暖紫色调——「黑身体 + 有色反光」这条已经在用了，下面沿着它往下做。

1 · 身体 × 眼睛 三种身体 × 1 / 2 / 3 只眼，头像和小人两种尺寸

眼睛数量是天生的区分：一只眼的居中放大，三只眼是两只 + 额头一只。嘴平时不画，只在说话、吃惊、高兴时出现。

2 · 小短手 圆头短手，和身体同色；没有腿，靠弹跳和滚动移动

3 · 表情 眼睛形状 + 用身体颜色盖掉眼白一角当眉毛；嘴只在需要时出现

4 · 区分：体色 + 饰品 身体都是黑的，只换反光色调；饰品按位置分五类

体色很收敛（暗处都接近黑），只在反光圈和高光上体现，远看是「黑球带一点色」。真正一眼认人的是帽子——帽子是驾驶舱里唯一还能看清的饰品，所以每个有名字的角色帽子剪影都不一样。

饰品库

5 · 阵容 旁白、主角、战役里的车手：头像 · 小人 · 驾驶舱里

每人一套：体色 + 眼睛数 + 帽子 + 一两件身上 / 手里的东西。驾驶舱那一格是直接画进游戏的 1×1 驾驶舱模块里的样子。

6 · 站成一排 场景尺寸；再看一遍剪影（全涂黑），看靠帽子能不能认出每个人

7 · 规则（草案） 确认后写进 docs/visual-rules.md §9

  1. 身体永远是黑的圆碳球：暗部接近纯黑，只有左上的反光圈和一点高光带颜色（体色）。同一张画里身体大小基本一致，个别角色可以大一号（胖哈利、大块头比尔），但不改形状。
  2. 没有腿，一对圆头小短手，和身体同色、上沿一点反光。移动 = 弹跳或滚成一团。
  3. 眼睛 1～3 只，白眼睛黑眼珠；一只眼居中放大，三只眼是两只 + 额头一只。眼睛数是角色的固定特征。
  4. 嘴平时不画，只在说话 / 吃惊 / 高兴时出现一个小口。眉毛不单独画，用身体颜色盖掉眼白一角。
  5. 区分靠「帽子剪影 + 体色 + 一两件饰品」：有名字的角色帽子剪影不重复；饰品最多 3～4 件，远看不糊成一团。
  6. 三种尺寸同一份数据：驾驶舱（半径 3.3）只剩身体、眼睛、帽子（2 行像素）和胡子 / 围巾的一个颜色点；场景小人（半径 8）和头像（半径 19）全画。
  7. 颜色：饰品用调色板里的色；炉火色只用在头灯、马灯、余烬这类真的会发光的东西上（同 docs/art-direction.md 的语义色）。
