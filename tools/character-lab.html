这个世界里的人都是圆形小碳球：小短手、看不到腿，眼睛 1～3 只，不画嘴。长相都差不多，靠肤色、眼球颜色、假发和饰品认人。起点是现在驾驶舱里的蓝灰碳球（第 0 节）。

同一份角色数据按三种尺寸画：驾驶舱里（半径 3.3，和游戏一样）、场景小人（半径 8）、对话头像（半径 19）。全部是程序化像素画，定稿后直接搬进游戏。

v3：眼睛回到原驾驶舱的简笔画形式（为什么原来的更可爱，见第 1 节上面的对比）：

  • 眼睛横向宽、挨得近（两只加起来约占身体宽 75%），但面积只占身体约 20%：身体大部分还是黑的，一眼就是「长了眼睛的煤球」。
  • 眼睛是圆角方块，只有白底 + 一颗单色瞳孔；没有虹膜渐变、没有高光、没有睫毛。
  • 两只瞳孔都偏向同一个角（默认右下），像在好奇地看东西。
  • 「眼球颜色」现在就是瞳孔颜色，默认墨黑；只有玛莎、沃德豪斯（紫）、伊莎贝拉（绿）、比尔（青）、圣殿骑士团（红）保留彩色瞳孔当特征。
  • v2 的其他改动保留：不画嘴、肤色可往体色过渡、假发、试装台。

1 · 身体 × 眼睛 三种身体 × 1 / 2 / 3 只眼，头像和小人两种尺寸

为什么原驾驶舱里的碳球更可爱（逐像素量的，身体 7 像素宽）
  1. 眼睛宽、面积小：两只眼横向占身体宽 75%，面积只占 20%，身体大部分还是黑的。v2.1 眼睛面积占到 60% 以上（看上去接近 80%），身体只剩一圈边，像昆虫或面具，也不像煤球了。
  2. 简笔画眼睛：白底 + 1 像素瞳孔，只有两种颜色。v2 加的虹膜渐变、高光、睫毛是写实的动漫眼，和极简的身体不搭。
  3. 视线：两只瞳孔都在右下角，像在看东西；大虹膜居中则像在瞪人。
  4. 挨得近：两眼之间只隔 1 像素，显得稚气；眼睛推到身体两边会显得呆板。
  5. 反差和形状：黑身体配纯白眼、黑瞳孔，对比最强；原来是 2×2 方块，放大后应该是圆角方块，而不是平滑的椭圆。

眼睛数量是天生的区分：一只眼居中、宽一些；三只眼是两只 + 额头一只小的。没有嘴。

8 · 规则（草案） 确认后写进 docs/visual-rules.md §9

  1. 身体是圆碳球：皮肤分四级，从近黑往体色过渡（浓度可调），左上一圈反光 + 一点高光；可以再设第二种颜色，身体下半往它过渡。个别角色可以大一号，不改形状。
  2. 没有腿，一对圆头小短手，和皮肤同色。移动 = 弹跳或滚成一团。
  3. 眼睛 1～3 只，照原驾驶舱的简笔画：圆角方块白眼 + 一颗单色瞳孔，没有高光和渐变；两眼挨近，横向约占身体宽 75%，面积约 20%；瞳孔偏向同一个角。眼睛数和瞳孔颜色（默认墨黑）是角色的固定特征。
  4. 不画嘴。表情全靠眼睛：眼形变化，用皮肤颜色盖掉眼白一角当眉毛 / 眼皮。
  5. 区分靠「帽子剪影 + 肤色 + 眼球颜色 + 假发 + 一两件饰品」：有名字的角色帽子（或假发）剪影不重复；饰品最多 3～4 件。
  6. 三种尺寸同一份数据：驾驶舱（半径 3.3）只画身体、眼睛（2×2 白眼 + 1 像素瞳孔）、帽子（2 行）、假发两侧和胡子 / 围巾的一个颜色点；场景小人和头像全画。
  7. 颜色：饰品用调色板里的色；炉火色只用在头灯、马灯、余烬这类真的会发光的东西上。
