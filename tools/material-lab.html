材质语言 v2 第四轮 · 漆面、描线与精细纹理 · 2026-09-27

上一轮的问题：乌兹钢的晕染和彩色油光显得廉价；杂色斑脏；亮边染色看不出来；暗部 / 亮部染色分不出区别。这一轮全部去掉，换成区分度更强、也更「维多利亚机器」的三种手法：

① 漆面——模块的大面刷一层深色瓷漆，受光的亮边和斜面仍露出金属，像蒸汽机车的涂装（布伦瑞克绿、米德兰深红、海军蓝、黑漆……）；② 描线——离模块外沿 3 像素处一道 1 像素的金 / 奶白 / 朱红细线，自动算出来，不用逐个模块画；③ 精细纹理——细大马士革、机刻纹、花纹板、珍珠纹，只改明度、不带颜色，所以不会「油」。

层级思路（配好的方案按这个排）：钢 = 金属本色（掺一点青）→ 镀镍 = 亮银 + 精加工纹理 → 乌兹钢 = 暗钢 + 细纹，开始上漆和描线 → 以太 = 整套瓷漆涂装 + 金描线。熟铁保留。都不发光。
