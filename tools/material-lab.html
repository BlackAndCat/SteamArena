材质语言 v2 探索 · 2026-09-27

问题：现在的材料装饰层把金属像素整体染成材料色（钢染蓝、乌兹钢染紫、以太染青），再满铺一层纹样（镀镍斜条纹、乌兹钢大波浪、以太发光脉络）。染色是「混色」，会在调色板外生成一堆脏色；纹样不管模块的形体、铺满整个面，于是钢以上四种材料显得扎眼、廉价。黄铜（原画）和熟铁之所以好，是因为它们几乎没染色、纹理稀疏。

方向：学熟铁的路子——材料只换一组手挑的低饱和色阶（逐阶映射，不混色），特色放在反光方式和一阶以内的稀疏细节上，再把铆钉换成各材料自己的紧固件。这样绝大多数模块什么都不用改，只换皮就有材料感，而整车仍然是统一的冷铁基调。下面每一格都是游戏自己的渲染代码画的，只把材质处理换掉了。

方案 显示 放大 冷暖倾向强度100%

六条规则

  1. 换色阶，不染色。每种材料给冷铁 5 阶、暗铁 4 阶各配一组固定颜色，逐像素按阶替换。所有颜色都能列进调色板，不会冒出混色产生的脏色。
  2. 饱和度封顶。金属固有色的饱和度不超过约 20%（下表有标注）；材料的「身份色」只是灰里带一点冷暖，真正的高饱和色只留给语义色和 UI 的品质色块。
  3. 材料靠明度和反光区分，不靠色相。熟铁暗而哑、钢中灰而锐、镀镍亮而柔、乌兹钢暗且有暗纹、以太暗且带一丝青光——去色以后六种材料依然分得开（切到灰度看）。
  4. 纹理只走一阶、只落在平整面上。细节不碰描边和亮边，每 4×4 最多一个（守 art-direction §9 的细节密度），不做满铺图案。
  5. 身份靠小件。铆钉换成各材料的紧固件：钢是六角螺栓、镀镍是黄铜花钉、乌兹钢是金销、以太是发光铆钉。面积小、位置固定，一眼可辨也不抢戏。
  6. 发光是最高级的奖励。只有以太能发光，而且只在铆钉上；动画只有「以太铆钉慢慢呼吸」和「镀镍沿亮边的一道反光」，其余材料不动。

建议与待定

我的建议

  1. 用方案 C 的规则替换现在的装饰层：黄铜、熟铁的观感基本不变（熟铁本来就是这个路子），钢以上四种材料不再染色、不再满铺纹样。只改 sprites.js 里的 decorate 一个函数，所有模块自动生效。
  2. 色阶写进 js/palette.js（每种材料 9 色），和其他颜色一样锁定。
  3. 品质感主要交给 UI：卡片边框、材料色块、「史诗 / 传奇」字样继续用鲜明的紫、青；画面里只保留一点冷暖倾向。

需要你决定

  • A / B / C 选哪个（或者 C 去掉动画）。
  • 各材料的冷暖倾向是否合适：钢是中性灰、镀镍是近中性的亮银、乌兹钢带一点紫、以太带一点青。整车尺度下乌兹钢和以太比较接近——用顶栏的「冷暖倾向强度」拖一拖，告诉我哪个档位合适（100% 是现在的定义值）。
  • 紧固件替换：镀镍配黄铜花钉、乌兹钢配金销钉，你是否喜欢「镍 + 铜」这种维多利亚搭配。
