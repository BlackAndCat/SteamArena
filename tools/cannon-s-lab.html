小炮 · 造型与材质语法 探索 v2 · 2026-09-27

小炮（cannon_s）只占 1 个 24px 子格。本页两件事：① 五个造型方向，看哪种在 1× 下最像「一门小炮」又不和中炮、小臼炮、机枪撞；② 材质语法——材料不再只是给同一张图换色，而是换一套零件画法（工艺、光泽、纹理、紧固件、炮口、动态），让黄铜像铸的、熟铁像锻的、钢像车床上下来的。只做视觉，不改游戏。

约束 骨架不随造型和材料变

  • 占 1×1 子格 = 24×24 原生像素；像素大小和所有模块一样，不缩放大模块。
  • 耳轴固定在 (12, 13)，炮口在耳轴前 24px（piv / blen）＝ 伸出格子 12px：只有武器能出格，出格的半格就是「会伤人」的信号。
  • 仰角 −8°～30°，炮组绕耳轴整体转；后坐 4px（rcPx）。各材料 / 阶段之间炮口点不动，否则炮弹出膛位置对不上。
  • 要和这些区分开：中炮（2×1 横躺长炮）、小臼炮（1×1 朝天）、机枪（三根短管）、侧炮（悬臂支架）、将来的喷火器 / 蒸汽喷射器（喷口）。
  • 底下一条中性铁脚不跟材料走，负责接进车体框架，保证整车还是一台机器。

材质语法 材料换的是零件画法，不是颜色

现在的材料装饰层是「同一张图 → 金属像素换色 → 加一层纹样」。48px 的大模块还看得出纹样，到 24px 小件上基本只剩换色：乌兹钢像涂了紫漆，以太像涂了青漆。材质语法把每种材料拆成六个通道，模块只画骨架、调用零件：换材料 = 换零件画法。剪影骨架（占格、耳轴、炮口点、铁脚）不动，材料特色都落在 2px 以内的边缘和表面，所以类别靠剪影、材料靠做工，两件事互不干扰。黄铜 → 熟铁 → 钢正好也是真实火炮材料的演进顺序。

建议与待定

我的建议

  1. 造型选 C 卡隆短炮为主，A 小炮塔为备选。C 在 1× 下最像「炮」，粗炮身是材质语法最好的展示面，剪影和中炮（带炮架的长管）、小臼炮（朝天）、机枪（三管）都不撞；如果嫌它太古董，A 最保险但辨识度最弱。B 的镂空、D 的炮窗、E 的喇叭口各有亮点，可以留给以后的变体（比如 Boss 件、唯一件）。
  2. 材质语法先在小炮上试点，定下六种材料的零件画法后，按「甲片 → 中炮家族 → 其他」分批迁移；没迁移的模块继续用现在的装饰层，两套可以共存。
  3. 材料的色阶写进 js/palette.js（每种 5 阶），比装饰层运行时算出来的颜色更可控，也更符合「锁定调色板」。

需要你决定

  • 选哪个造型方向（或者哪两个组合，例如 C 的炮身 + A 的底座）。
  • T1「黄铜」要不要真的画成黄铜？现在游戏里 T1 叫黄铜，但画面是冷铁 + 黄铜箍。材质语法里 T1 小炮是铸黄铜炮身（历史上早期火炮就是青铜 / 黄铜铸的），但如果甲片、装甲也跟着变成黄铜，开局整车就会一片金黄，重蹈 Steamlands「全是一个颜色」的覆辙。可选：只有武器的炮身按材质语法显示黄铜，结构件的 T1 保持冷铁。
  • 以太的炮口闪光要不要换成青白色（现在规定只有炉火色能发光，以太纹路是唯一例外）。
  • 这套材质语法是否推广到全部模块（工作量：每个模块把「画金属」改成调用零件，按模块计大约是原来重画一个阶段造型的三分之一）。
