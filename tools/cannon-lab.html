直射火炮 · 高阶造型语言 探索 v2 · 排布规则 · 2026-09-27

问题：镀镍起，描线 + 越来越复杂的造型让零件脱离了蒸汽朋克、显得「高级」；乌兹钢的圆顶和圆润线条像外星科技；以太的线路 + 圆润 + 看不清的细节，又难认又太科幻。

v2（按反馈）：定方案 A，保留铭牌、铆钉、包角铁、压力表、铁箍。上一版零件乱放、压住散热口、铭牌没有固定位置——这一版先定排布规则：炮塔侧面露出来的那块立面按上下分区（接缝线 → 散热区 → 铭牌区），角上是包角位，上层炮廓左侧是表位，每区只放一类东西、互相留 1 像素空隙。散热口也是语言：T1～2 两道横槽 → T3～4 三道 → T5 双列 → T6 斜百叶。造型：T1～T4 方方正正，T5～T6 自带斜向板。

v1 的思路：① 造型只用直线：第三阶段不再用圆顶和刻槽，改成阶梯式炮廓 + 铁箍炮身 + 方形制退器（维多利亚工业建筑和早期火炮的语言）。② 高阶身份交给一套可复用的装饰零件：铭牌、包角铁、铆钉排、顶饰、檐口线脚、徽记、压力表、铁箍。每件都小、直、放在固定挂点上，其他模块也能直接用。③ 每档只换或只加一件，不靠堆细节。④ 材质颜色用已定稿的六档（和游戏一致），描线可以在顶栏关掉对比。

规则草案

  1. 只用直线和直角。高阶不再出现圆顶、弧形炮廓、刻槽、喇叭口；圆只用在耳轴、压力表、顶饰这种本来就圆的小零件上。
  2. 每档只换或只加一件零件。高阶靠「更好的那一件」，不靠更多的细节。
  3. 零件有固定挂点。铭牌 / 徽记在最大平面的左下，包角铁在外沿角上，铆钉排在顶接缝，顶饰在最高点，檐口在顶边。
  4. 黄铜件是身份，铁件是结构。铭牌、徽记、顶饰是黄铜（醒目），角铁、铆钉、铁箍是铁（跟材料走、不抢戏）。
  5. 描线可选。瓷漆本身已经足够区分材料，描线会让画面变复杂；建议关掉，或者只留给最高一档。

需要你决定

  • A v2 的排布规则、散热口排法、「T1～4 方正 / T5～6 斜板」是否 OK。
  • 描线是全部关掉，还是只留给以太（现在按顶栏开关，默认关）。
