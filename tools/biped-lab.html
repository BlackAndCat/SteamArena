双足底盘升级版 · 设计探索

以现役双足底盘为基础：六个品质各一款升级版（腿越来越帅，不再是两根小铁棍），再加五款探索版。 每款同一份造型代码按三个轴对比：像素密度（1× 原生 48px / 2× 精细 96px：车体按 2 倍放大、只有腿是精细像素，两边显示成一样大）、 腿长（×1 = 现在的格高；×1.5 ≈ 整车抬高 16px）、腿的分布（每格一对 / 整段底盘只要一对巨腿）。「剪影 / 灰度」是 docs/art-direction.md 里的验收测试。

初步结论
  1. 限制主要不在像素密度，而在腿只能待在底盘这一格里（胯到地面只有 33px）。整车里腿只占四分之一高度，画得再细也显小。
  2. 腿长 ×1.5（原生 48px 像素、整车抬高约 16px）就能把圣骑、龙骑画出层次，不需要混用两种像素密度。
  3. 「整段一对巨腿」最像双足机甲；每格一对腿在三格底盘上是六条腿，像蜈蚣。代价：底盘的受击 / 毁坏表现要改成按整条腿算（例如大腿、膝、小腿分别对应不同格）。
  4. 2× 精细的细节更好（马刺星轮、齿轮齿、鳞片），但车体是放大的粗像素、腿是细像素，同屏两种像素大小，违反 art-direction §9「全游戏只能有一种像素大小」。建议不用，或者整套美术一起升到 96px。
