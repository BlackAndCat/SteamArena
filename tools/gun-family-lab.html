按 docs/visual-rules.md 把直射火炮的做法推到中炮（2×1，横躺长炮）。形体和直射火炮一一对应：T1～2 敞开式炮架 + 低矮前挡板 → T3～4 方方正正的平顶炮廓把炮座罩起来 → T5～6 炮廓前沿做成斜板。炮管三种和直射火炮同一套：素管 + 一道箍 + 小方制退器 → 炮尾套筒 + 连体阶梯制退器 → 粗炮身 + 三道铁箍 + 大方制退器。散热口：2 道竖缝 → 3 道 → 成对竖缝 → 斜百叶。小模块做减法：不放铭牌；镀镍起只在炮廓左上加一块小压力表（直径 7）；接缝铆钉 2 → 3 → 4 颗，T1～3 黄铜、镀镍起钢质淡青；钢起有包角铁。

v3（按反馈）：摇架恢复到接近旧版的大小，耳轴处画回方形固定螺栓（方框 + 中心点）；散热口每档至少 3 个：T1～2 三道竖缝 → T3～4 四道密排竖缝 → T5 两行短竖缝 → T6 两行斜百叶。

v1 试过「高防盾 / 斜防盾」，在 24px 高的模块上读成一根竖杆，已放弃，改成和直射火炮同构的炮廓。分区按炮管的仰角范围（−8°～30°）核对过：压力表、散热口、铆钉都在炮管扫不到的地方。

臼炮（高抛火炮）· 2×2 v1 6× 分区图（T6 原画，55°）

臼炮是抛射火炮，剪影最容易和中炮撞。参考 19 世纪攻城 / 岸防臼炮（如 13 英寸「独裁者」）：炮管又短又粗、越往炮口越粗（和所有加农炮的收细方向相反），炮口一道厚箍、大口径黑洞；炮耳在炮尾，夹在炮耳座里；整门炮坐在低矮厚重的炮床上，炮口永远朝天。活动设计：炮耳上一个小齿轮跟着炮管转，带动两侧两个大齿轮反向转——瞄准时齿轮真的在转（下面的仰角行能看到三个角度下齿轮的相位不同）。齿轮用重炮的纯黄铜画法、垫在最后面。炮管按旋转后的坐标逐像素算，82° 也不锯齿。形体：T1～2 方炮床 + 方炮耳座 → T3～4 两层台阶炮床 + 加厚炮耳座、炮管一道铁箍 → T5～6 炮床前沿斜切 + 梯形炮耳座、两道铁箍。散热口在炮床正面左段、铆钉在炮床上沿右段、钢起包角铁。耳轴 (24,30)，炮口末端离耳轴 24。
