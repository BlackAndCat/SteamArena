你说的 → 这一版怎么改
  1. 小部件不像素 → 全部重画成像素九宫格：四阶色、左上光、1 像素描边；去掉渐变、圆角、模糊阴影和斜放的纸（像素图不旋转）。字：标题黑体，其余用宋体点阵，钱和数值用 5×7 像素数字。
  2. 东西太多、意义不明、形态错 → 删掉黑板下的抹布和粉笔、筹码堆、卷起的蓝图、零散提示纸条、海报上的装饰行、锁住的锦标赛路牌；拉杆改成真的调速杆：黄铜扇形齿板 + 铁杆 + 皮握把，悬停往前推。
  3. 铁板纹理扎眼 → 铁板改成平的四阶铁，只在四角打铆钉。
  4. 纸没质感 → 纸是像素做的：毛边描边、边缘用抖动做出旧黄、稀疏的纸纤维和斑点；旧纸、牛皮纸、下注凭单的绿纸各一套。
  5. 没有齿轮 → 齿轮放进会动的部件：主按钮里的齿轮（悬停转）、推动齿条表的小齿轮、带动钱数字轮的齿轮、换层旋钮、拉杆轴心和扇形齿板、设置按钮。
