机甲外观（已进游戏）

这一版改了什么
  1. 步幅按步频算：走 1.6～2 步 / 秒、跑 2.4 步 / 秒左右，步长 = 车速 ÷ 步频。原来一步比腿还长（脚够不着地）；现在走路两脚在胯前后约 ±24px，跑步时脚落在身体正下方附近（约 ±15px）。
  2. 走 = 倒立摆：着地占 60%（有双脚着地段），着地腿在胯正下方时整车最高；摆动脚走一条关键姿势插值出来的圆滑曲线（先脚尖蹬地、过胯下时最高、落地前脚跟先着）。
  3. 跑 = 弹簧-质量：着地只占 36%，着地中段压到最低（下压），两脚都离地时被抛到最高（腾空）。摆动腿按跑步关键姿势走：蹬离 → 脚跟往后上收 → 顶膝往前 → 小腿伸出 → 落在身体下方。机甲版收着点，粗腿不会蜷成一团。
  4. 走跑自动过渡：车速 76～100 px/s 之间平滑从走变成跑（现在双足基础速度 78、超速满 97.5，所以超速时会跑起来）；跑起来躯干往车头前倾，每高一大格多 1px（设计稿的「整行错位」）。
  5. 你的决定都记下了：晶枝腿归标准腿；跳跃件用 A；提速件改装在胯部（不占大腿位，下一轮出方案）；头盔改成两格横躺的部件、两边补零件（进游戏时做）。
