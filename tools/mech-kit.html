全局子格套件 · 视觉验证

所有模块缩小到 1/4：一个旧格（48px）分成 2×2 个子格（24px），像素大小不变。零件是公共的，双足、履带、蜘蛛共用一套，每个零件有铁制 / 钢制两种品质外观。只做视觉，不涉及数值。

两层，规则对所有底盘一样
  1. 车体层：驾驶舱、燃炉、水罐、甲片。占格、需要支撑，连成一副车体框架（露在外面的角切 4px）。
  2. 附加层（原来的侧挂层和肢体层合并）：机械臂（格斗 / 剑 / 锤 / 巨炮 / 盾）、重炮、侧炮。画在车体前面，可以盖住车体格；武器可以伸出格外；必须压在或贴着车体零件上；附加层零件之间不重叠；瞄准时只打附加层（沿用侧炮规则）。
  3. 肩膀属于机械臂模块：关节轴套 + 肩甲，肩甲不超过大臂的两倍宽。
这一轮的改动
  1. 原来胯两侧的小金点是「卡箍」（把腰挂模块夹在胯上），看不懂，已删掉。改成胯体向两侧伸出一块同材质的法兰板，压在腰挂模块上，用一颗大铆钉固定。
  2. 头盔居中：胯改成对准一列子格的中心，头盔（1×1）放在同一列就正好在胯的正上方；胸口 3 子格宽，也以这一列为中心。
  3. 机械臂从 1×2 放大到 2×3，肩膀在胸口中间，手到腰的高度。
