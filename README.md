# 蒸汽竞技场（原型）

维多利亚蒸汽朋克 · 像素风 · H5 载具构筑 + 竞技场对战。纯 HTML/CSS/JS，无构建步骤，无外部依赖。

## 运行

脚本是普通 `<script>`，直接双击 `index.html` 也能玩；推荐起一个静态服务器：

```bash
python -m http.server 5173
```

然后打开 http://localhost:5173 。美术自查页：http://localhost:5173/tools/spritesheet.html

控制台输入 `SA.reset()` 可清空存档重来。

## 玩法速览

- **工坊**：商店/借贷、修理、改装、订单、赛事、下注、云车库、图例、出战。
- **改装**：8×6 格子，最高叠 6 层（含底盘行），模块必须有下方支撑。两个平面：主体层 + 侧挂层（只能挂侧炮）。撞击武器（铲斗装在底盘前，撞角/蒸汽撞锤装在装甲前）必须是该行最前端。
  - 操作集中在底部操作栏：选模块再点格子放置；点已有模块直接替换（换下的回库存），再点同款模块拆下；车上的模块可拖动移动/对调，拖出车外放回库存；右键拆下、Esc 取消、Delete 拆下选中模块。
  - 改装台上允许悬空、乱放；出战（以及交付订单）前所有模块必须一路连到底盘，不合规的模块整体红色闪烁，选中的模块绿色闪烁。
  - 没有库存的模块可以直接放，确认后自动购买；钱不够会询问是否向银行贷款补齐差额。
- **动力**：模块消耗动力；锅炉供给动力但产热；需求不能超过底盘承载上限，超过锅炉供给会拖慢装填。
- **热量**：锅炉和开火产热，水箱耗水冷却；热量到 100 即“烧干停机”判负。
- **战斗**：A/D（或屏幕按钮）左右移动，有惯性（起步加速、松手滑行制动，越重越慢），冲撞按相对速度造成撞击伤害；移动鼠标瞄准，炮管按角速度慢慢转向准星，点线为炮管当前指向的弹道；直射武器（直射火炮/机枪/侧炮）有仰角射界、散布扇区与命中率提示，并有概率打飞，高抛火炮指哪打哪（× 为落点）；按住左键开火（第一发有点火延迟），松开停火降温；履带任意一段被毁即掉链，整车无法移动；有 ≥2 种武器时用数字键 1–9 切换当前武器组（直射火炮 / 高抛火炮 / 机枪 / 侧炮）。高抛火炮不会被己方模块挡住。炮弹按抛物线飞行，打中路径上第一个模块（虚线框提示）。准星对准侧炮时只和侧挂层碰撞，不会被装甲挡住。主体层武器前方有己方模块会被挡住，侧炮不会。镜头会自动缩放以框住双方载具。
- **街头赛**：锦标赛之外的赚钱比赛，三档评分上限（200/300/450），车太强进不了场。对手是随机拼装的小角色，评分贴近你的车；只拿奖金，不计声望、不影响赛程，损伤照常带回。
- **蓝图库**：改装页可把当前车辆存成本地蓝图（独立于存档，`SA.reset()` 不会清掉），一键应用时先拆回车上的模块、缺的按原价补买；另有 4 张不能删除的官方基础蓝图。
- **成长**：六轮赛事夺冠；声望 ★4 后军方来收购原型机；民间订单按条件买图纸授权；可借贷、可押自己赢。
- **云车库**：分享码 `SA1.…` 可导入他人载具打友谊赛（当前用 localStorage 模拟云端）。

## 代码结构

| 文件 | 内容 |
|---|---|
| `js/palette.js` | 锁定调色板 + 语义分类（颜色由 category 推导） |
| `js/modules.js` | 模块注册表、全局常量 |
| `js/sprites.js` | 48px 程序化像素精灵（带缓存）、铆接车体框架、一战履带、蓝图视图、整车渲染、高亮描边 |
| `js/vehicle.js` | 格子规则（严格摆放 / 改装台自由摆放、移动对调、出战检查 `issues`）、属性计算、分享码 |
| `js/content.js` | 赛事对手、订单、云车库预置、官方蓝图、街头赛档位与角色 |
| `js/state.js` | 存档、经济（购买、贷款）、赔率、军方报价、云车库接口 |
| `js/ui.js` | 工坊中枢与所有面板、确认框/付款（含贷款询问）、战后结算 |
| `js/blueprints.js` | 蓝图库：官方蓝图 + 本地蓝图的保存/覆盖/删除/应用 |
| `js/street.js` | 街头赛：随机小车生成、按评分配对手、评分上限 |
| `js/editor.js` | 改装编辑器：响应式布局、底部操作栏、点选/拖放、就地购买 |
| `js/battle.js` | 竞技场：加速与撞击、直射/高抛弹道与预览、武器组切换、镜头、AI（`SA.Battle.debug.step(秒)` 可手动推进） |
| `docs/art-direction.md` | 美术统一与辨识度方案 |
