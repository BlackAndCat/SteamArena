# 蒸汽竞技场（原型）

维多利亚蒸汽朋克 · 像素风 · H5 载具构筑 + 竞技场对战。纯 HTML/CSS/JS，无构建步骤，无外部依赖。

## 运行

脚本是普通 `<script>`，直接双击 `index.html` 也能玩；推荐起一个静态服务器：

```bash
python tools/serve.py        # 等同 python -m http.server 5173，但禁止浏览器缓存（git pull 后刷新即是新代码）
```

本地预览服务默认只监听 `127.0.0.1`。页面覆盖、关卡车与进化任务的写入接口只接受本机同源页面；本机命令行请求没有 `Origin` 时仍可使用。服务写入校验可运行 `python -m unittest tools/test_serve_security.py`。

侧边栏「页面管理」可开启编辑：点击页面元素，选择当前文字或父元素，删除文字或隐藏所选元素。修改立即留在浏览器草稿；支持浏览器文件选择接口时，首次点「选择保存文件」并选本项目的 `text/steam-arena/zh-CN.json`，此后编辑、删除和「清除覆盖」会自动写入该文件，刷新后复用已授权文件。若浏览器不支持直接写文件，仍可用 `tools/serve.py` 保存，或点「导出 JSON」手动替换文件。出战只列已击败的关卡和当前下一场，未解锁章节及未来场数不展示。

需要让 AI 快速操作或批量测试 HTML5 游戏时，可启动零依赖的本地 MCP：`python tools/html5_game_mcp.py`。它通过 Chrome DevTools Protocol 提供脚本执行、键鼠输入、固定步长推进和蒸汽竞技场无画面模拟；完整工具说明见 [docs/html5-game-mcp.md](docs/html5-game-mcp.md)。

然后打开 http://localhost:5173 。美术自查页：http://localhost:5173/tools/spritesheet.html；双足底盘升级版设计探索：http://localhost:5173/tools/biped-lab.html ；真双足样机：http://localhost:5173/tools/biped-v2.html ；全局子格套件：http://localhost:5173/tools/mech-kit.html ；地形美术样机：http://localhost:5173/tools/terrain-lab.html ；悬挂与爬坡样机：http://localhost:5173/tools/suspension-lab.html ；进化擂台与数值自测：http://localhost:5173/tools/evolve.html（旧 `tools/sim.html` 入口自动跳转到自测页签）；关卡车工作台：http://localhost:5173/tools/stage-editor.html

进化擂台可选择整章或某一关，设置种群、代数、每对局数、并行数与随机种子后生成报告；运行时显示完成步数 / 总步数、当前章关与代数、已用时间，并每 5 秒按本次累计速度估算剩余时间，刷新页面可继续查看。总步骤包含候选评估、关卡整理、筛选和报告保存。需要安装 Node.js，并用 `python tools/serve.py` 启动本机服务。局部生成保留其他关卡结果，未审阅预算标为草案，预演不写正式关卡。分类网格可收藏车型、打开工作台修改；工作台的“保存到进化擂台”使用拼装车间里的车名，自动标为手工修改并清除旧战绩，返回后可作为后续进化种子。收藏与手工车保存在当前浏览器的独立本机候选库中，不随最近三份报告清理；不符合当前模块表、预算或缺少本关奖励件的车保留原样，但跳过进化并提示原因。候选车必须携带奖励模块，节约与实战强度统一尺度后按 6:4 计分；详情显示计算结果。胜率来自同档标尺的换边实战，显示样本数，平局计半胜；它不等同于新手玩家通关率。数值自测与报告在同一页切换，已有自测结果继续保留。

侧边栏底部的「开发者」按钮是开发入口（其中「试驾场」可以任选场地，对手从战役各关 / 终局锦标赛 / 官方蓝图 / 我的蓝图 / 云车库 / 随机街头车里挑，还能改对手的材料、AI 性格和枪法，用你现在的车打友谊赛）：上面列出全部开发工具（数值自测、进化报告、关卡车工作台、模块精灵表、机甲套件、双足样机与设计探索），点一下在新标签页打开，不用记网址；下面是存档调试：一键全部解锁（外加 £10000 和锭）、跳到任意章节、加钱、清空存档。新工具页加到 `js/camp-ui.js` 的 `DEV_TOOLS` 就会出现在面板上。关卡车工作台也可从这里直接打开。控制台同样可用：`SA.reset()` 清空存档；`SA.dev.goto(n)` 直接跳到第 n 章（前面的解锁全部发放），`SA.dev.unlockAll()` 全部解锁，`SA.dev.money(n)` 加钱；`SA.dev.designMode()` 开启隔离设计存档，`SA.dev.loadStageCar(ch, st)` 把关卡车送进车间，`SA.dev.saveStageCar(ch, st)` 保存，`SA.dev.exitDesign()` 恢复正式存档。

模块属性工作台：在「开发者」面板或关卡车工作台打开 `tools/module-editor.html`，按名称或类别选模块，直接调整文字和玩法属性并点「一键保存」。使用本地 `tools/serve.py` 时直接写入 `js/modules.js`；Chrome / Edge 静态打开时首次选择该文件并授权写入，此后浏览器记住文件句柄。保存成功后工作台自动刷新；已打开的游戏页面刷新后读取新属性。

进化任务开始前会预检所选全部关卡的标尺构筑，失败提示对应章节、关卡、奖励和预算。`node tools/evolve-chapters-check.js` 用小种群检查第一至第五章共 15 关的奖励保底、90 台标尺及完整生成流程，已接入 `node tools/evolve-check.js`；生成成功与胜率 / 地形 / 奖励效果达标分别报告。

审计边界回归可分别运行 `node tools/battle-audit-check.js`（双足耐久、实伤计分、辅助件与持续伤害）、`node tools/share-audit-check.js`（损坏分享码和旧蓝图）及 `node tools/visual-audit-check.js`（双足专属外观与车间渲染循环）。三组检查也已接入 `node tools/evolve-check.js`，完整后台检查会先运行这些边界用例。

新档初始车为黄铜四件车：履带、小锅炉、小机枪、头盔驾驶舱。已有档保持原车；控制台 `SA.dev.resetVehicle()` 可主动换回这台车，原件保留耐久、改装和唯一身份退库，资金与战役进度不变。剧情数据由 `SA.StoryData.list/get/set/save/point` 管理；开发者模式下的战前控制台保留剧情编辑、播放与继续开战，并可在新窗口直达当前关卡车工作台。工作台的关卡文字页可编辑名称、驾驶员、赛前介绍和弱点提示；所有现有章节均可手工保存，保存后已打开的游戏页会同步，正式开战时读取最新关卡车。非战役对战打开普通工作台。专项检查：`node tools/story-dev-check.js`，已纳入完整后台检查。

多人 / 多代理协作的规则、分工、Git 流程见 [docs/collab.md](docs/collab.md)；后台和视觉工作清单分别见 [astra 看板](docs/board-astra.md) 和 [Opus 看板](docs/board-opus.md)。

游戏节奏、最终目标和后续阶段见 [docs/game-design.md](docs/game-design.md)；模块清单、外观分级、美术工作量和排期见 [docs/module-plan.md](docs/module-plan.md)。

## 玩法速览

特殊武器：抛射架（原“火箭架”，id 不变）以 18～85° 高抛四发齐射，保留散布、溅射和装填殉爆；鱼叉缆绳实时连到被拴住的目标模块。蒸汽喷射器仅 T1～T3，喷火器仅 T4～T6；喷火图纸在第三章获得，镀镍材料开放后可购买。旧越界喷射武器按原材料换成对应种类，保留材料、改装和耐久比例。

- **战役**：序章 + 五章，共 18 关，从铁匠铺后院打进水晶宫。序章顺序为小水罐 → 甲片 → 铲斗；甲片关“补丁号”首次通关固定获得 1 块黄铜甲片，读档和重打不重复发放。每一场对手都是一道构筑考题（赛前点它就能侦察车况和弱点）；通关一章解锁新模块、新材料、新功能和更大的改装台（4×3 → 8×6）。开局只有「出战」，车间、商店、侧挂层、蓝图库、银行、下注都随战役逐步出现。战役和终局锦标赛每赢一场，可以从对手剩下的完好模块里缴获一件——只限你还没有的零件（车上和库存里都没有同款同材料或更好的）和史诗 / 传奇特殊件；街头赛、友谊赛不缴获。通关后开放终局「伦敦蒸汽大奖赛」赛季循环。
- **材料 = 品质**：黄铜 ×1 → 熟铁 ×1.2 → 钢 ×1.45 → 镀镍 ×1.75 → 史诗 乌兹钢 ×2.1 → 传奇 以太合金 ×2.5，换色区分（驾驶舱、锅炉、水箱保留原色，只在四角钉上材料色的角铁）。选中车上的模块即可升级（耐久、伤害、动力、水、冷却、撞击、承重、护甲一起放大，重量和产热不变）；前四级花钱、随战役解锁，史诗 / 传奇还要消耗乌兹钢锭 / 以太结晶（Boss 掉落、赛季冠军）。库存按「模块 + 材料」分开记。
- **地形**：每场比赛有场地（赛前在对阵面板里能看到）：平地、货箱（木头的，能挡一两发炮弹；车一顶上去就碾碎，只被拖慢一下，碎木堆也减速）、泥地（按底盘减速：履带 ×0.8、四足 ×0.65、双足 ×0.45）、土坡（炮弹打在坡上就停，上坡慢下坡快；整车按坡度倾斜贴地，炮口、弹道、命中判定跟着一起算）、工厂后院（两道小坡夹一摞高货箱）、矿坑（矿渣堆加两边泥坑）。战役每关有自己的场地，终局锦标赛六轮六种场地，街头赛随机。开发者面板里可以挑场地和对手试驾。
- **驾驶舱辅助设备**：选中驾驶舱可以加装瞄准镜（蓄力更快、准星缩得更小）、装弹仓（装填 −15%）、陀螺稳定仪（车身晃动 −30%）、测距仪（直射散布 −15%）。每个驾驶舱 2 个槽、同一种不重复，全车生效，驾驶舱被毁就失效，卸下半价回收；随战役解锁。
- **投降**：对手满足任一条件持续 1 秒就挂白旗：① 开不了火、也撞不了人；② 开不了火、只剩撞击件，耐久不到一半；③ 残血（不到 20%）而你的耐久比例是它的 3 倍以上。Boss 只在 ① 时投降。战斗暂停，由你决定接受（立即获胜、对手零件原样保留、额外声望 +1）还是继续打。
- **护甲**：铁装甲 3、重装甲 6、铲斗 5、履带 2、四足 1（随材料放大），每挨一发先减掉固定伤害（最少保留 25%）：机炮打装甲只冒火星，直射火炮才凿得穿。
- **两个页面**（左侧铆钉钢板导航切换，手机上变成顶部横条）：
  - **车间**：改装台 + 商店 + 修理 + 蓝图库/云车库 + 图例（画布左下角的「?」）。左上角黄铜铭牌是车名、评分、状态和一键修理，展开看性能条；右上角切换主体层/侧挂层，旁边的「蓝图库」按钮把右侧面板切到蓝图库；下方是操作栏；右侧面板默认是模块清单（按类别分组的大图列表，分组条可折叠；默认只列有库存的，打开「商店」开关才列出没有的）。
  - **出战**：左边选比赛（战役 / 街头赛 / 终局锦标赛，按解锁显示），右边是对阵、下注和出发按钮；车况有问题会直接给出「去车间」「全部修理」。
  - 侧边栏的「资金」点开是银行（借款 / 还款）；钢板上的徽标提示车间里有几项出战问题。
- **改装**：8×6 大格，每个大格分成 2×2 小格（全车 16 × 12 小格），最高 6 层（含底盘的两行小格）。大模块占 2×2 小格，可以错开半格摆；甲片、小水罐、驾驶舱占 1 个小格，水罐占 1×2（竖），中炮占 2×1（横）；小模块都是 24px 原生像素画。模块四周紧贴一个已连到底盘的模块即可（可以侧挂、悬挑），撞击件不能当支撑。摆放时模块中心跟着鼠标，底盘自动贴到最底两行。两个平面：主体层 + 侧挂层（只能挂侧炮，要整个挂在主体模块上）。撞击武器（铲斗装在底盘前，撞角/蒸汽撞锤装在装甲或底盘前）必须是它那几行的最前端；直射武器炮管那一行（模块下半格）前方不能有己方模块。旧存档、旧蓝图和 SA1 分享码会自动换算成小格。
  - 操作集中在底部操作栏：选模块再点格子放置；点已有模块直接替换（换下的回库存），再点同款模块拆下；车上的模块可拖动移动/对调，拖出车外放回库存；右键先取消选中或拖动，空手时才拆下指针下的模块；Esc 取消、Delete 拆下选中模块。
  - 改装台上允许悬空、乱放；出战前所有模块必须一路连到底盘，不合规的模块整体红色闪烁，选中的模块绿色闪烁。
  - 没有库存的模块可以直接放，钱够就直接买下，不弹窗；只有钱不够时才询问是否向银行贷款补齐差额。点选或拖入模块安装后都保持选中，可以连续放置；库存用尽后自动按次购买，右键取消。选中库存模块可以直接买 / 卖。
  - 购买、修理、升级或应用蓝图实际扣款时，鼠标旁会浮出「−£金额」并淡出；使用库存、取消付款或资金不足未付款时不显示。
- **重量**：每个模块 = 基础 250 kg + 自身重量（撞角比铲斗重，重装甲最重），改装还会加重；总重不能超过底盘承重（履带 3.5 t / 四足 2.4 t / 双足 2.4 t 每格），超重不能出战。车越重加速、刹车、起步都越慢；撞击伤害与自身车重成正比（6 t 为 ×1，0.5~3 倍），撞击面自己也吃 30% 反作用伤害。
- **动力**：动力需求 = 设备耗能（武器、驾驶舱、撞锤）+ 行驶耗能（每吨 0.3）；锅炉供给不够时车速和装填一起按比例下降。装甲不耗动力，代价是重量。
- **速度**：最高速度 = 底盘基础速度 × 动力比（锅炉富余最多超速到 125%），以 km/h 显示（一格 ≈ 1.5 m）。底盘手感：双足起步和刹车最快、跑得最快但走起来最晃；四足刹车最慢，但移动中最平稳；履带居中。
- **改装**：选中车上的模块可以加装炮盾（武器，每级耐久 +30%）/ 附加装甲 / 加固裙板 / 加厚撞面（每级耐久 +25%），最多 3 级，每级 +120 kg。纯属性升级，不占格子；鼠标停在模块上会显示军衔杠。拆下模块时改装件按一半价格回收。
- **热量**：机器只要运转就会慢慢积热（站着不动也一样）；锅炉、行驶、起步憋气和开火都会产热，也都会直接耗水；水箱耗水冷却，越热冷却越猛；热量超过 75 属性条红光闪烁，到 100 即“烧干停机”判负。
- **碰撞**：两车逐行（小格行，被地形抬高时按实际高度对齐）相撞——每一行各自最前端的模块互相顶住，一对模块只算一次，底盘伸得再长也只在底盘那两行挡路，上层的撞角能越过光秃秃的底盘撞到后面的模块；撞角装在底盘前则能直接顶坏对方的履带 / 腿。
- **驾驶舱与驾驶员**：基础驾驶舱只占 1 个小格、坐 1 名驾驶员；2×2 联合驾驶舱坐 4 人（第四章通关解锁）。全车活着的驾驶员每比 1 多一个，就多一组武器由他们接管（你切换武器组，他们跟着换到剩下的），自己挑目标开火，但没你准；战斗中武器组按钮上会标「驾驶员」。原来的副驾驶已取消，旧存档和分享码里的副驾驶自动换成联合驾驶舱。
- **新增模块族**：开局已有 1×1 车载机枪和 1×2 竖式锅炉，第一章通关开放 1×2 重机枪，第四章通关开放 3×3 大型锅炉和大水箱。原 2×2 `mg` 改名「机炮」，id、数值、开局库存和双联机枪保留；旧存档按已通关章节补发解锁。巨炮改为高抛间接射击，等待炮管转到可达目标后开火，AI 会进退调整射击距离。
- **火炮**：新档使用 1×1 车载机枪，前期可换装横躺的 2×1 中炮；2×2 直射火炮熟铁起才有（第一章通关解锁），黄铜关卡里的敌车改用中炮。
- **胜负**：驾驶舱全毁或烧干停机即判负；对手投降并被接受也算赢；敌方若武器打光、水也烧干、又没有撞击件，也判负（这条对玩家不生效）；时间到按剩余耐久比例判定。
- **平手**：双方都失去动力（锅炉全毁）或没有能开火的武器，持续 1.5 秒且没有炮弹在飞，即判平手：各拿奖金的一成作出场费；锦标赛这一轮重赛、退还赌注。
- **修理**：修满只要原价的 1/20，按损伤比例计费。
- **战斗**：A/D（或屏幕按钮）左右移动，有惯性（停稳后起步要等锅炉「库吃库吃」冒几口蒸汽，松手滑行一大段，反向要先停稳，越重越慢），冲撞按相对速度造成撞击伤害；铲斗 / 撞角的击退和撞锤的推力都是两车之间动量守恒的一对冲量（单次击退有上限），重车的速度变化总比轻车小；被撞得比自己能开的最高速度还快时履带 / 脚会打滑急停，不会一撞滑出老远；车顶有耐久 / 热量 / 水三条细条和实色闪烁的警报牌（过热、缺水、失去动力、掉链、无武器可用），自己的警报也会显示在准星下方，热量过 75 时屏幕四周泛红光；移动鼠标瞄准，炮管按角速度慢慢转向准星（画面上的炮管 / 枪管绕耳轴跟着转，炮弹从转动后的炮口射出），点线为炮管当前指向的弹道；直射武器（直射火炮/机炮/侧炮）有仰角射界、半透明散布扇区与命中率提示（散布按三角分布，扇区边缘真的会打到；初级直射火炮 ±12°，满距离不蓄力打前排模块约五成命中），并有概率打飞，高抛火炮指哪打哪（× 为落点）；黄铜齿轮准星：按住左键蓄力，瞄准度 0→100%，齿轮收紧、散布扇区同时缩小；缩圈幅度和瞄准速度是载具属性，前期基础值只能把散布缩小 30%、直射火炮约 2.4 秒蓄满（以后的瞄准镜等部件通过模块字段 aimShrink / aimSpeed 加成，最多缩小 75%）；蓄满闪绿光自动开火，提前松手立刻开火，开火后坐力会把准星震开；机枪这类快枪按住就连发，齿轮随之飞转；慢炮只要在装填就显示摆动的沙漏（按住也一样：蓄满自动开火后手还按着，会先变沙漏、装好再变回齿轮接着蓄力，沙漏外圈的环显示蓄力程度）；准星对准的模块整格白色高亮闪烁（侧炮和普通模块一样，只在准星旁标「侧炮」）；散布扇区由 17 条弹道组成，各自飞到真正撞上的模块 / 货箱 / 地面为止，相邻弹道之间连成条带一次填满，不留缝；扇区宽度变大立刻跟上、变小慢慢收；战斗节奏默认 0.75 倍，战斗界面底部有速度滑条（0.3–1.5 倍，记在本机）；移动、起步、刹车会让车身晃动：散布变大、蓄力变慢还会被抖散，很难打出绿光（四足最稳，双足最晃）；准星与沙漏合一：装填中准星变成来回摆动的沙漏（外圈淡环仍显示稳定度），装好了变回齿轮；机枪这类快枪不切沙漏，齿轮每打一发咔哒转一齿、领头的齿闪一下，内圈细弧显示装填；开火有制退与复进（炮管后坐再慢慢推回），反作用力把车往后推、整车前后晃动并微微抬头，越重的车越稳；履带任意一段被毁即掉链，整车无法移动；有 ≥2 种武器时用数字键 1–9 切换当前武器组（直射火炮 / 高抛火炮 / 机炮 / 侧炮）。手操的这一组是齐射：组里每门炮都装好了才一起开火，沙漏也等最慢的那门；其他驾驶员管的组各打各的。高抛火炮不会被己方模块挡住。炮弹按抛物线飞行，打中路径上第一个模块（弹道中心先打中的不是准星对准的那个时，用橙色角框标出来）。准星对准侧炮时只和侧挂层碰撞，不会被装甲挡住。主体层武器前方有己方模块会被挡住，侧炮不会。镜头会自动缩放以框住双方载具。场地左右无限延伸，想退多远退多远，不会被堵在角落；背景是一座圆形竞技场：远处厂房和一圈看台画在圆筒上，镜头移动时看台跟着转，像车在绕着场地跑。
- **街头赛**：战役之外的赚钱比赛，三档评分上限（200/300/450，随战役章节放大），车太强进不了场。对手是随机拼装的小角色，用已解锁的材料，评分贴近你的车；只拿奖金，不计声望、不影响赛程，损伤照常带回。
- **蓝图库 · 云车库**（车间底部操作栏的第二个页签）：「存为蓝图」保存当前车辆（独立于存档，`SA.reset()` 不会清掉），可改名、覆盖、删除、分享；4 张官方基础蓝图不能删除；云车库里别人的车也能直接套用。应用蓝图时先拆回车上的模块、缺的按原价补买。「导入分享码」把别人的车存成自己的蓝图。
- **成长**：战役逐章解锁；可借贷、可押自己赢；通关后每个赛季的锦标赛对手换上更好的材料，夺冠奖励以太结晶。
