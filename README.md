# 蒸汽竞技场（原型）

维多利亚蒸汽朋克 · 像素风 · H5 载具构筑 + 竞技场对战。纯 HTML/CSS/JS，无构建步骤，无外部依赖。

## 运行

脚本是普通 `<script>`，直接双击 `index.html` 也能玩；推荐起一个静态服务器：

```bash
python -m http.server 5173
```

然后打开 http://localhost:5173 。美术自查页：http://localhost:5173/tools/spritesheet.html

控制台输入 `SA.reset()` 可清空存档重来。

## 玩法速览

- **两个页面**（左侧铆钉钢板导航切换，手机上变成顶部横条）：
  - **车间**：改装台 + 商店 + 修理 + 蓝图库/云车库 + 图例（画布左下角的「?」）。左上角黄铜铭牌是车名、评分、状态和一键修理，展开看性能条；右上角切换主体层/侧挂层，旁边的「蓝图库」按钮把右侧面板切到蓝图库；下方是操作栏；右侧面板默认是模块清单（按类别分组的大图列表，分组条可折叠；默认只列有库存的，打开「商店」开关才列出没有的）。
  - **出战**：左边选比赛（锦标赛 / 街头赛 / 友谊赛 / 委托），右边是对阵、下注和出发按钮；车况有问题会直接给出「去车间」「全部修理」。
  - 侧边栏的「资金」点开是银行（借款 / 还款）；钢板上的徽标提示车间里有几项出战问题、出战页有几份可交付委托。
- **改装**：8×6 格子，最高叠 6 层（含底盘行），模块必须有下方支撑。两个平面：主体层 + 侧挂层（只能挂侧炮）。撞击武器（铲斗装在底盘前，撞角/蒸汽撞锤装在装甲或底盘前）必须是该行最前端。
  - 操作集中在底部操作栏：选模块再点格子放置；点已有模块直接替换（换下的回库存），再点同款模块拆下；车上的模块可拖动移动/对调，拖出车外放回库存；右键拆下、Esc 取消、Delete 拆下选中模块。
  - 改装台上允许悬空、乱放；出战（以及交付订单）前所有模块必须一路连到底盘，不合规的模块整体红色闪烁，选中的模块绿色闪烁。
  - 没有库存的模块可以直接放，确认后自动购买；钱不够会询问是否向银行贷款补齐差额。选中库存模块可以直接买 / 卖。
- **重量**：每个模块 = 基础 250 kg + 自身重量（撞角比铲斗重，重装甲最重），改装还会加重；总重不能超过底盘承重（履带 3.5 t / 四足 2.4 t / 双足 2.4 t 每格），超重不能出战。车越重加速、刹车、起步都越慢；撞击伤害与自身车重成正比（6 t 为 ×1，0.5~3 倍），撞击面自己也吃 30% 反作用伤害。
- **动力**：动力需求 = 设备耗能（武器、驾驶舱、撞锤）+ 行驶耗能（每吨 0.3）；锅炉供给不够时车速和装填一起按比例下降。装甲不耗动力，代价是重量。
- **速度**：最高速度 = 底盘基础速度 × 动力比（锅炉富余最多超速到 125%），以 km/h 显示（一格 ≈ 1.5 m）。底盘手感：双足起步和刹车最快、跑得最快但走起来最晃；四足刹车最慢，但移动中最平稳；履带居中。
- **改装**：选中车上的模块可以加装炮盾（武器，每级耐久 +30%）/ 附加装甲 / 加固裙板 / 加厚撞面（每级耐久 +25%），最多 3 级，每级 +120 kg。纯属性升级，不占格子；鼠标停在模块上会显示军衔杠。拆下模块时改装件按一半价格回收。
- **热量**：机器只要运转就会慢慢积热（站着不动也一样）；锅炉、行驶、起步憋气和开火都会产热，也都会直接耗水；水箱耗水冷却，越热冷却越猛；热量超过 75 属性条红光闪烁，到 100 即“烧干停机”判负。
- **碰撞**：两车逐行相撞——每一行各自最前端的模块互相顶住，底盘伸得再长也只在底盘那一行挡路，上层的撞角能越过光秃秃的底盘撞到后面的模块；撞角装在底盘前则能直接顶坏对方的履带 / 腿。
- **副驾驶**：控制类模块。每个副驾驶接管一组你当前没在手操的武器（你切换武器组，他跟着换到剩下的），自己挑目标开火，但没你准；战斗中武器组按钮上会标「副驾驶」。
- **胜负**：驾驶舱全毁或烧干停机即判负；敌方若武器打光、水也烧干、又没有撞击件，也判负（这条对玩家不生效）；时间到按剩余耐久比例判定。
- **平手**：双方都失去动力（锅炉全毁）或没有能开火的武器，持续 1.5 秒且没有炮弹在飞，即判平手：各拿奖金的一成作出场费；锦标赛这一轮重赛、退还赌注。
- **修理**：修满只要原价的 1/20，按损伤比例计费。
- **战斗**：A/D（或屏幕按钮）左右移动，有惯性（停稳后起步要等锅炉「库吃库吃」冒几口蒸汽，松手滑行一大段，反向要先停稳，越重越慢），冲撞按相对速度造成撞击伤害；移动鼠标瞄准，炮管按角速度慢慢转向准星（画面上的炮管 / 枪管绕耳轴跟着转，炮弹从转动后的炮口射出），点线为炮管当前指向的弹道；直射武器（直射火炮/机枪/侧炮）有仰角射界、半透明散布扇区与命中率提示，并有概率打飞，高抛火炮指哪打哪（× 为落点）；黄铜齿轮准星：按住左键蓄力稳住准星，齿轮收紧、散布扇区同时缩小（最多缩到 30%），蓄满闪绿光自动开火，提前松手立刻开火，开火后坐力会把准星震开；移动、起步、刹车会让车身晃动：散布变大、蓄力变慢还会被抖散，很难打出绿光（四足最稳，双足最晃）；准星与沙漏合一：装填中准星变成来回摆动的沙漏（外圈淡环仍显示稳定度），装好了变回齿轮；机枪这类快枪不切沙漏，齿轮每打一发咔哒转一齿、领头的齿闪一下，内圈细弧显示装填；开火有制退与复进（炮管后坐再慢慢推回），反作用力把车往后推、整车前后晃动并微微抬头，越重的车越稳；履带任意一段被毁即掉链，整车无法移动；有 ≥2 种武器时用数字键 1–9 切换当前武器组（直射火炮 / 高抛火炮 / 机枪 / 侧炮）。高抛火炮不会被己方模块挡住。炮弹按抛物线飞行，打中路径上第一个模块（虚线框提示）。准星对准侧炮时只和侧挂层碰撞，不会被装甲挡住。主体层武器前方有己方模块会被挡住，侧炮不会。镜头会自动缩放以框住双方载具。
- **街头赛**：锦标赛之外的赚钱比赛，三档评分上限（200/300/450），车太强进不了场。对手是随机拼装的小角色，评分贴近你的车；只拿奖金，不计声望、不影响赛程，损伤照常带回。
- **蓝图库 · 云车库**（车间底部操作栏的第二个页签）：「存为蓝图」保存当前车辆（独立于存档，`SA.reset()` 不会清掉），可改名、覆盖、删除、分享；4 张官方基础蓝图不能删除；云车库里别人的车也能直接套用。应用蓝图时先拆回车上的模块、缺的按原价补买。「导入分享码」把别人的车存成自己的蓝图。
- **成长**：六轮锦标赛夺冠；声望 ★4 后军方来收购原型机；民间委托按条件买图纸授权；可借贷、可押自己赢。
- **友谊赛**：出战页挑战云车库里的车（当前用 localStorage 模拟云端），不结算奖金、不留损伤。

## 代码结构

| 文件 | 内容 |
|---|---|
| `js/palette.js` | 锁定调色板 + 语义分类（颜色由 category 推导） |
| `js/modules.js` | 模块注册表（含重量、承重）、全局常量、重量 / 改装辅助函数 |
| `js/dynamics.js` | 动态处理模块：阻尼弹簧（车身晃动）、后坐曲线（制退 / 复进）、相位与量化（履带、腿、供弹链），每辆车一个动画器 |
| `js/sprites.js` | 48px 程序化像素精灵（带缓存）、铆接车体框架、一战履带、整车渲染、高亮描边、改装军衔杠 |
| `js/vehicle.js` | 格子规则（严格摆放 / 改装台自由摆放、移动对调、出战检查 `issues`）、属性计算、分享码 |
| `js/content.js` | 赛事对手、订单、云车库预置、官方蓝图、街头赛档位与角色 |
| `js/state.js` | 存档、经济（购买、贷款）、赔率、军方报价、云车库接口 |
| `js/ui.js` | 通用界面：弹窗 / 确认框 / 付款（含贷款询问）、顶栏导航、属性条、载具预览、银行、战后结算 |
| `js/blueprints.js` | 蓝图库：我的 / 官方 / 云端蓝图的统一列表，保存、改名、覆盖、删除、分享、导入、应用 |
| `js/arena.js` | 出战页：锦标赛 / 街头赛 / 友谊赛 / 委托，对阵、下注、出发 |
| `js/street.js` | 街头赛：随机小车生成、按评分配对手、评分上限（界面在出战页） |
| `js/editor.js` | 车间：改装台、铭牌、底部操作栏（模块 / 蓝图库）、点选与拖放、就地买卖与修理、图例 |
| `js/battle.js` | 竞技场：加速与撞击、直射/高抛弹道与预览、武器组切换、镜头、AI（`SA.Battle.debug.step(秒)` 可手动推进） |
| `docs/art-direction.md` | 美术统一与辨识度方案 |
