# 真双足 · 视觉语言与平衡系统 v0.2

> v0.2（2026-09-25）：进游戏的定稿规则见 §8，取代 §1 的占格规则和原来的待定项。

> 2026-09-24 · 样机：`tools/biped-v2.html`（腿型沿用 `tools/biped-lab.html` 的六档 + 探索版）

## 0. 为什么要改

现在的双足是「一排桌腿上摆一个箱子」：

- 腿的数量随格数增加，三格底盘就是六条腿，看上去像蜘蛛，和四足用的是同一套「横梁 + 一排腿」的画法。
- 平板横梁像桌面，上身看不出是被腿扛着的：没有支点，也看不出重心。
- 腿只有 33px 高，只占整车高度的四分之一。
- 玩家照着履带的造法把车搭成房子，双足没有任何理由长得不一样。

目标：双足一眼就是**直立行走的机甲**，而且玩法上引导玩家造**精简的机体**。

## 1. 占格规则

```
行 0-3  躯干     最宽 3 格（胯列左右各 1 格），往上照常需要支撑
行 4    腰胯层   [腰挂][ 胯 ][腰挂]      胯 = 底盘本体；腰挂位可以放模块，也可以空着露出大腿
行 5    腿区     不能放任何模块，一对腿在这里迈步
```

- 一台车**只有一个双足底盘、只有一对腿**（近侧一条，远侧一条压暗、错位）。
- 双足底盘是 **1 格宽 × 2 格高**：行 5 是腿（受击判定 = 腿），行 4 是胯（受击判定 = 胯 / 陀螺仪）。
- 腰挂位（胯左右各一格）让双足不用长得太高，腰部也有用处：挂装甲就是草摺，挂水箱、机枪就是腰包、腰炮。
- 躯干最宽 3 格，超出就判「超宽」，不能出战。这条从结构上堵死了「搭房子」。

旧存档迁移：多格双足只保留一格作为胯列，其余底盘退回库存。

## 2. 平衡系统

胯里装着一台黄铜陀螺仪，它就是平衡系统，在画面上也看得见。

**重心偏移 d**：所有模块（含底盘）的重量按列加权，求重心相对胯中心偏了几格，车头方向为正。

| d | 状态 | 表现 | 建议效果（待调） |
|---|---|---|---|
| \|d\| ≤ 0.25 | **平衡** | 身体直立，陀螺平稳 | 边走边打散布最小；可以用踢击 |
| d > 0.25 | **前倾 · 冲锋姿态** | 躯干前倾，陀螺偏向前 | 起步 +、冲撞伤害 +；行进射击更晃 |
| d < −0.25 | **后仰 · 炮台姿态** | 躯干后仰 | 更吃得住后坐（后坐位移 −）；起步 − |
| \|d\| > 0.6 | **失衡** | 躯干来回摇晃，陀螺乱晃 | 不能出战（和超重同一类出战问题） |

- **头重脚轻**：重心高出腰胯层超过 1.8 行，晃动加大。躯干高了就要付出代价。
- 偏载不是纯惩罚，而是一种造法选择：前重就是冲锋机，后重就是炮台机。
- 底盘品质 = 陀螺品质：档位越高，容差越大（例如失衡阈值从 0.6 提到 0.9）、晃动越小。改装件「加固裙板」可以换成「陀螺配重」。
- 胯被打坏 = 陀螺停转，容差归零，一直大幅摇晃；腿被打坏 = 跪地，不能走，但还能开火。

**编辑器指示**（样机里的「平衡指示」）：

- 从重心垂下一条黑白点线，末端挂一个黄铜铅坠。
- 地面上画出支撑区：绿 ±0.25 格，黄铜 ±0.6 格，外面是炉火红。
- 铭牌上加一个水平仪气泡，UI 色沿用压力表绿（承载语义）。

## 3. 视觉语言

保留 `biped-lab` 里六档腿的造型语言（工装 Mk.II → 鹭步 → 掷弹兵 → 蒸汽圣骑 → 钟表巨像 → 熔心龙骑），只改它们挂在车上的方式。

1. **剪影是倒三角**：躯干宽（≤3 格）→ 收成 40px 的胯 → 一对长腿。胯关节到地面 67px（约 1.4 格），腿以胯为支点放大约 2 倍画，**仍然是 48px 原生像素**，不混用像素密度。
2. **胯是唯一的承力点**：从上往下依次是黄铜回转环（刻痕随步伐转）、倒梯形胯体、陀螺仪窗。陀螺转子一直在转，偏载时倾向重的一侧，失衡时乱晃。
3. **腰挂是挂着的，不是落地的**：腰挂模块的两个底角切斜 12px，和胯之间有两道黄铜卡箍。它读起来像草摺或枪套，不像一个放在地上的箱子。
4. **收腰、切肩**：躯干最底一行的外端底角切斜 9px，每列最顶那格的外侧上角切斜 6px。切口补 1px 最暗铁描边。这样箱子堆读起来就是一副躯干。
5. **姿态靠整行错位**：按重心偏移，每往上一行多错开一点，最多约 2px 一行，走路时再额外前倾一点。只做整像素平移、不旋转，符合 art-direction §9。
6. **远侧腿**：压暗一阶，相对近侧腿向右 6px、向上 3px；画在躯干后面。
7. **步态**：放大后的腿每半个周期后蹬约 28px，正好对上行进 30px，脚不打滑。整车起伏 4px。
8. 胯的材质跟腿型走：圣骑、裙甲、罩袍用亮钢；钟表用黄铜；龙骑的陀螺轴心是炉火色（能源语义：自带动力）。

待做：落脚时脚下喷一口蒸汽加轻微震屏；踢击动画；跪地（腿毁）和陀螺停转（胯毁）的表现。

## 4. 四足 → 蜘蛛

四足保留「每格一对腿」，干脆往蜘蛛走，和直立的双足拉开剪影：

- 机身压低，是暗铁甲壳加一道黄铜饰线；相邻格的甲壳连成一片。
- 腿往外张：底盘前半段的腿朝前伸，后半段的朝后伸；远侧腿方向相反、压暗。
- **膝盖必须高过机身顶板**，这是蜘蛛的标志。
- **用膝盖高度区分型号**：伏地蛛（膝盖只高一点，矮、宽、稳）、高脚蛛（膝盖高出机身一大截）。以后四足的品质档也按膝高、腿粗来分。
- 腿的结构：粗股节、带黄铜箍的锥形胫节，膝和髋是铁关节毂。

## 5. 落地步骤（改游戏时）

1. **数据**：`biped` 改成 1×2 的底盘，每车最多一个；按品质拆成六档（腿型 + 陀螺容差）。
2. **规则**（`vehicle.js`）：腿区禁放；腰挂位 = 胯列 ±1；行 3–4 最宽 3 格；重心、头重算进 `stats`；超宽、失衡进 `issues`。
3. **渲染**（`sprites.js`）：双足改为胯 + 一对腿；躯干切角、整行错位；四足换成蜘蛛腿。样机里的光栅器（遮罩 + 四阶上色）可以直接并入。
4. **战斗**（`battle.js`）：姿态影响起步、晃动、后坐；平衡时解锁踢击（贴身时腿当撞击件）。
5. **编辑器**：铅垂线、支撑区、水平仪；规则分区提示（样机里的「规则分区」）。
6. **兼容**：分享码、官方蓝图、对手车（「双足舞者」要重搭）、旧存档迁移。

## 6. 子格模块验证（2026-09-25，`tools/mech-kit.html`）

把模块缩小到 1/4（24px 子格，一个旧格 = 2×2 子格，像素大小不变），以轻骑、圣骑为核心各画了一套零件：头盔驾驶舱、燃炉、水罐、小水罐、甲片、机械臂、臂炮、盾牌。只做视觉验证。

- **兼容**：躯干缩到 3×3 子格，和长腿的比例对得上，不需要放弃双足机甲。
- **肢体层**：手臂、盾、臂炮画在车体前面，可以盖住胸口、伸出车体外。现在的侧挂层直接扩展成肢体层。
- **零件套装**：同一品质的腿、肩、肘、盔共用母题（圣骑的扇翼、黄铜包边），拼出来才协调。
- **不能混用**：旧的 48px 模块和子格零件放在一起，比例和细节密度都对不上。要走子格，所有模块都得重画。
- 24px 零件照样能认出来（水罐青、炉火橙、舷窗 / 目缝里的眼睛），代价是细节变少。

## 7. 全局子格 + 附加层（2026-09-25，`tools/mech-kit.html`）

定下来的方向：

- **全局子格**：所有模块都用 24px 子格重画，零件是公共的，双足、履带、蜘蛛共用，不给双足单独开零件线。同一零件用铁制 / 钢制两种外观区分品质。底盘是大件（2 子格高），履带沿用现在的精灵。
- **两层，规则对所有底盘一样**：
  - **车体层**：驾驶舱、燃炉、水罐、甲片。占格、需要支撑，连成车体框架，露在外面的角切 4px。
  - **附加层**：原来的侧挂层和肢体层合并。包括机械臂（格斗 / 剑 / 锤 / 巨炮 / 盾）、重炮、侧炮。画在车体前面，可以盖住车体格；武器可以伸出格外；必须压在或贴着车体零件上；附加层零件之间不重叠；瞄准时只打附加层（沿用侧炮规则）。
- **机械臂 2×3 子格，肩膀属于手臂模块**：关节轴套加肩甲，肩甲不超过大臂的两倍宽。肩在胸口中间，手到腰的高度。有机械臂时，躯干后面自动补一条压暗的空手远侧臂。
- **头盔居中**：胯对准一列子格的中心，1×1 头盔放在同一列，就正好在胯的正上方；胸口 3 子格宽，也以这一列为中心。
- **胯和腰挂的连接**：原来的黄铜卡箍（小金点）看不懂，改成胯体向两侧伸出的同材质法兰板，压在腰挂模块上，用一颗大铆钉固定。

## 8. 进游戏的定稿规则（2026-09-25，用户决定）

> 本节取代 §1 的占格规则和原来的「待定」。§2 平衡系统、§3 视觉语言仍然有效，和本节冲突时以本节为准。规则和数据归 astra，画面归 Opus（见 `docs/collab.md`）。

**已定：**

1. **一对腿**：一台车始终只有一对腿（近侧一条、远侧一条），**不管双足底盘占几格宽**。底盘宽度按格数计算承重、耐久和重量，腿不会随格数变多。
2. **底盘整件**：双足底盘占最下面两层：下层是腿区（不能放任何模块，受击 = 腿），上层是胯（受击 = 胯 / 陀螺仪）。腿画在胯下的中心。
3. **高度**：整车高度上限就是改装台的 6 层，和其他底盘一样，不另设躯干上限。双足的腿区和胯占掉最下面两层，所以躯干最多 4 层。躯干太高只受 §2 的「头重脚轻」软性惩罚。
4. **宽度**：取消 §1 的「躯干最宽 3 格」，宽度只受改装台限制。腰挂位 = 胯行左右各 1 格。
5. **撞击件**：可以装，包括铲斗、撞角、蒸汽撞锤和 Boss 撞击件。装在胯行（或腰挂位）的最前端，其余规则和其他底盘一样。
6. **侧炮（侧挂层）**：可以装，挂在躯干或腰挂位上。
7. **平衡系统**：§2 全部进游戏，数值暂定：
   - 重心偏移决定姿态：平衡 / 前倾冲锋 / 后仰炮台；失衡不能出战；
   - 头重脚轻；
   - 底盘材料越好，容差越大；
   - 胯被毁 = 陀螺停转、一直大幅摇晃；腿被毁 = 跪地，不能走但还能开火。
8. **踢击**：平衡姿态下贴身时，腿当撞击件用（§5 第 4 条）。

**迁移**：旧存档、分享码、官方蓝图、关卡里的多格双足，换成同宽的新双足整件：原来的底盘行变成胯行，腿区另外加在下面。如果整车因此超过 6 层，去掉最高一层，模块退回库存。关卡车（独角兽、双足舞者等）重新搭一遍。
