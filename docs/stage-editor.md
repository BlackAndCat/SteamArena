# 关卡车工作台使用说明

## 三步设计流程

1. 用 `python tools/serve.py` 启动本地服务器，打开 `tools/stage-editor.html`，在左侧选关后点“开始 / 继续拼装”。页面会自动进入独立设计存档：钱、材料、改装台和全部非退役模块都已准备好，不需要先开商店或购买模块。导入的分享码或候选车也能直接进入车间继续拼装。
2. 在内嵌的正常游戏车间里选模块、点车体格子安装；也可以直接把右侧模块拖到车体、拖回库存、对调和拆下。拼装页操作结束后点“结束拼装并恢复正式存档”，正式存档的车辆、钱和解锁不会被设计过程改动，刚拼好的车会留在工作台草稿里等待保存。切换关卡前先保存；刷新页面或切换关卡会丢弃未保存的草稿。
3. 在“关卡文字”“奖励与解锁”“强度调节”页签编辑其余字段。通关解锁模块点“打开模块选择窗口”，窗口会显示游戏模块图和名称；“固定种子测试”查看胜率与 95% 区间，再点“一键试驾”在游戏试驾场亲手打一场。确认后点“保存为手工关卡车”。

## 按钮含义

- “保存为手工关卡车”写入 `js/stage-cars.js`，记录自动带 `source: 'manual'`、规则指纹、时间和 `locked: true`。
- “解锁”把当前记录的 `locked` 改为 `false`，这样进化器可以重新生成它；“重新锁定”恢复保护。
- “拿候选车作底稿”读取进化报告保存到本机的候选车；导入后仍要点击保存才会成为手工记录。
- “打开模块选择窗口”用图片卡片勾选通关后要解锁的模块；窗口里的名称来自模块定义，不需要填写内部代码。
- “固定种子测试”用开局车和之前几关的参考构筑，按正向 / 反向各打一组无画面对局，显示胜率、Wilson 95% 区间、平均用时、结局分布和目标颜色。
- “一键试驾”把当前车临时放进 `steam_arena_evolve_picks`，打开游戏现有试驾场；不会结算或修改正式存档。
- “结束拼装并恢复正式存档”退出隔离设计存档；也可以在控制台调用 `SA.dev.exitDesign()` 完成同样操作。

如果服务器不可用，工具会把完整记录复制到剪贴板，并提示粘贴回 `js/stage-cars.js`；不要只复制单车的分享码，因为分享码不包含材料和改装等级。

## 确认进化器没有覆盖

锁定记录会在 `node tools/evolve.js --sample 1 3` 的报告里显示 `source: manual`、`locked: true` 和“手工锁定，未改动”，同时仍作为 Boss 标尺车或对手参考车参与计算。`node tools/evolve-check.js` 包含锁定补丁拒绝夹具，并检查 `js/stage-cars.js` 字节内容不变。规则指纹明确排除 `js/stage-cars.js`，所以改手工车不会让进化报告因为文件本身变化而过期。
