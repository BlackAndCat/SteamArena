# UI 精简计划（院子 / 车间 / 出战黑板 / 弹窗 / 战斗 HUD / 出征）

## 背景

用户觉得现在的 UI 又多又杂，常用操作不够显眼，也不够好够着。但具体哪些多余，很难一条条说清。

我先把每个界面的元素全部列了一遍（院子、车间、出战黑板、弹窗、战斗 HUD、出征），然后按三条标准筛：

1. **常驻的说明文字**：把规则写在屏幕上，而玩家多操作一次就自己明白了。这就是"把玩家当弱智"的那一类。
2. **同一件事报好几遍**：比如车有几项问题同时出现在 5 处，过热同时有 6 个信号。
3. **常用操作要多走一步**：出战只能拖拉杆，点一下没用；车间没有「全部」页签。

**判断原则**：
- 画面、动画、数字已经表达了的，删掉文字。
- 同一信息只留最该出现的那一处。
- 规则说明只在第一次教程里出现一次。
- 需要查的时候，有一张随时能打开的「操作一览」。
- 悬停提示属于玩家主动去看的内容，可以保留，但要删掉其中重复教程的段落。

**不改的东西**：数值、规则、AI、存档格式。用户已经定下的设计也不改：院子 3 块路牌，驾驶台 HUD，10 个武器键位，空键位留空，下注单和笔迹。

## 一、车间（`js/editor.js`、`js/ui.js` 中的 pxStats）

### 加
- **模块清单加「全部」页签。** 这个页签现在只在关卡车工作台出现（`editor.js:795、800、809` 用 `stageWorkbench()` 把它挡住了），去掉这个限制即可。
  - 「全部」放在页签列的第一个，新存档默认打开它。玩家上次选的页签照旧记在 `steam_arena_cat_v1`。
  - 「全部」里按 `CAT_ORDER` 分组，每组前面一条细分隔条，显示类别色条、类名和件数。这条分隔复用现在的 `.cat-head`。
  - 如果模块的 `cat` 不在 `CAT_ORDER` 里，就归到最后的「其他」组。现在骑士盾臂 `knight_shield`（`cat: "armor"`）在清单里根本看不到，这样它至少能在「全部」里出现。改它的 cat 写进给 astra 的交接。
  - 单一类别页签里，去掉顶上重复页签名的 `.cat-head`。

### 删
- 左栏标题「性能单」。
- 底栏空闲时那句常驻操作说明（`editor.js:717`："从模块清单选一个，再点格子放置…Shift + 拖动…"）。
- 手里拿着零件时底栏的操作说明（`:663`，"点格子连续放置…右键取消"）。库存、购买价这类状态信息保留。
- 选中车上模块时底栏的操作说明（`:695`，"点空格子移动；拖到别的模块上对调…"）。
- 商店相关的重复说明：开关左边的状态文字（`:736`），以及清单顶上的横幅（`:840`）。只留「商店」开关，清单行上已经标了「£ 购买」。
- 五根仪表悬停提示里的 `ABOUT` 段落（`ui.js:184-190`，和教程台词一字不差）。明细数字保留。
- 「棋盘点 = 装上手里的零件以后」这条图例（`ui.js:202`）。改成仪表上直接显示「现值 → 装上后」，见下面「改」。
- 问题数从 5 处减到 2 处：只留左栏评分行（带问题列表）和出战拉杆旁的红字。删掉底栏空闲时的 `problems[0]`（`:714`），出战按钮悬停时的整串问题也删掉。
- 死代码：`keyStats()`（`:757-773`，没有任何地方调用），顶栏里没用到的 `nav` / `fix`（`ui.js:124、127`）。

### 改
- 「?」帮助按钮：现在弹的是「图例与规则」，里面没有图例，一半讲的还是战斗。改成**「操作一览」卡片**，内容是车间的键鼠操作表（左键、右键、拖、Shift+拖、滚轮、Delete、Esc）加上战斗的键位表。这张卡同时也能从设置里打开。（战斗键位表里会补上现在没有任何地方提到的空格开火、W/S 跳和蹲。）
- 底栏空闲时什么也不显示，只留右端的拉杆。

## 二、出战黑板（`js/arena.js`）与拉杆（`js/ui-px.js` throttle）

### 改（常用操作）
- **点拉杆两端的「出战 →」/「← 回院子」字样，拉杆自己动画推到底并执行。** 拖动照旧可用，杆子不加按钮。现在单点杆子只会晃一下（`ui-px.js:590、608`），这一处保留。
- 出战黑板上按回车 = 出战。
- 黑板记住上次选的模式页签（现在只有出征会记），街头赛、锦标赛、支线回来不用再点一次页签。
- 教程里的黑板导览（`tutorial.js:106-116`）原先逐块讲黑板布局，压到只剩一句「点出战或推杆开打」。

### 删
- 拉杆下面常驻的操作说明（`arena.js:364`，"A / D 移动 · 鼠标瞄准…"），这些挪进「操作一览」卡片。
- 赛程列表的常驻页脚：「打过的可以重打，不奖不罚」（`:132`），支线页的「竞技场外：没有奖金和声望…」（`:130`）。
- 「还有 N 关 · 制作中」这一行（`:112`）。「下一章：…」保留，作为灰色锁住的章节标题。
- 「重打不发奖励」这条规则现在说了 3 遍，只留海报上一句短的「↺ 重打 · 无奖金」。列表页脚里那句删掉，重打结算弹窗里的那句也删掉。
- 海报和档案里重复的名字：
  - VS 区去掉车名，只留肖像和评分。
  - 对手档案去掉「车辆 / 车手」两行，只留档案独有的信息（速度对比等）。
  - 档案里的评分删掉，VS 区已经有了。
- 右栏「号外」（`:355`）。它只是重复上一场的结果，结算弹窗已经报过。
- 章节开场弹窗里那句「点对手看它的车和弱点，再回车间对症改装」（`camp-ui.js:46`）。这句不但多余，还说错了，黑板上并没有能点的对手。

### 出征页签（开发版）
- 删掉列表页脚「一路往右冲；见好就收…」、装车卡里的两句提示（`:228-230`），「怎么回家」从 4 行压成 1 行。

## 五、战斗 HUD（`js/battle-view.js`）

### 删（飘字）
- 「投降」飘字（`battle.js:1769` 发出的 text 事件，在画面层忽略掉）。白旗、电报、对话框已经说过了。
- 侧炮连带掉落时每门炮冒一个的「!」（`battle.js:703`，同样在画面层忽略）。
- 「弹开」（`battle-view.js:36`）：敌人打我时不再出。我打敌人时保留，但节流到最多 1.2 秒一次，免得高射速刷屏。跳弹是克制链的核心，玩家打出去的那一发需要看到。

### 改（纸条 `dash-note`，`:1324-1345`）
- 纸条不再重复五盏灯已经亮着的状态（过热、缺水、动力、履带、武器）。
- 只报**能马上采取行动**的瞄准问题：超出射界、超出射程、被挡住。
- 平时那一行从「瞄准 敌方X · 命中率约 N% · 稳住 N%」压成「命中率约 N%」。目标是谁，看高亮；稳住了没有，看准星。
- 删掉「（橙色角框）」这类解释画面的括号，还有「换高抛火炮试试」「可以用 A/D 冲撞对手」这类教学腔。这些只留在序章教程里。
- 删掉「紧急泄压」下面的「限一次」（`:1262`）。按钮用过后变灰，悬停提示里也有说明。

### 加（够得着）
- **Esc 暂停**：弹出一个小铁牌，上面有「继续 / 撤退 / 操作一览」。撤退和返航的确认框弹出时，战斗也暂停（现在不会停）。只在画面层的循环里跳过 step，不改 `battle.js`。
- 「紧急泄压」加快捷键 Q，键名印在按钮上。

## 实施方式

按记忆里的经验，用户点头以后**一次全部应用**，不分期。按界面分几个 `vis:` 提交，每个都立刻推送：

1. `doc:` 把本计划存成 `docs/ui-cleanup-plan.md`，并在 `docs/board-opus.md` 记一笔。
2. `vis:` 车间：「全部」页签，删说明，「操作一览」卡片。
3. `vis:` 出战黑板和拉杆：点字样即出战，回车出战，记住页签，删重复内容。
4. `vis:` 院子、设置、弹窗。
5. `vis:` 战斗 HUD：飘字、纸条、Esc 暂停、Q 泄压。
6. `vis:` 出征的飘字和清点界面。

每个改画面的提交都更新 `js/build-vis.js`。

## 验证

- 改过的 JS 都跑一遍 `node --check`；然后跑 `tools/` 下和 UI 相关的检查：`legacy-dom-author-check.js`、`visual-audit-check.js`、`shop-rules-check.js`、`prologue-plate-check.js`，以及其他会读这些文字键的检查。
- 用 `python tools/serve.py 5190` 起服务，在内置浏览器里过一遍：
  - 新存档：标题 → 序章第一关能开火 → 院子 → 车间。确认「全部」页签默认打开，按类分组，骑士盾臂出现在「其他」组。
  - 出战黑板：点「出战 →」能开打，回车也能开打，换模式回来页签还记着。
  - 战斗：Esc 能暂停、继续、撤退；Q 能泄压；没有「投降」「!」飘字；纸条平时只显示命中率。
  - 出征一趟：拾取不再冒字，清点界面没有矛盾句。
- 每个界面截前后对比图，给用户看。
- 跑一场试驾场，打开 `tools/spritesheet.html` 确认正常。
