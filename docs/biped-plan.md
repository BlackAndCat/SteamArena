## 0. 问题

**承重**：双足每车只能有一件，承重 2400（黄铜）～6000（以太合金，×2.5）。履带每大格 3500、可以接成一排，四足每件 2400、可以首尾相连。后期变强主要靠多带火力、多带甲，所以双足越往后越落后。

2026-10-05 用 `SA.V.stats` 实测：

| 配置 | 总重 / 承重 | 结论 |
|---|---|---|
| 双足：驾驶舱 + 燃煤锅炉 + 小炮（没有水箱） | 2.09 t / 2.40 t（87%） | 最小的合法双足，已经快满 |
| 双足：驾驶舱 + 燃煤锅炉 + 水箱 + 直射火炮 | 2.94 t / 2.40 t | 超重，出不了战 |
| 履带一格：同上配置 | 3.04 t / 3.50 t | 可以出战，还能加宽 |

**速度档次被超速抹平**：锅炉富余时，所有底盘都能超速到 1.25 倍（`K.SPEED_BOOST`）。纸面最高速：

| 底盘 | 基础 | 满超速 |
|---|---|---|
| 履带 | 48 | 60 |
| 四足 | 62 | 77.5 |
| 双足 | 78 | 97.5 |

超速的履带 ≈ 不超速的四足，超速的四足 ≈ 不超速的双足。档次之间是重叠的，双足的速度优势看不出来。另外泥地里双足最慢（×0.45，四足 ×0.65，履带 ×0.8）。

## 2. 总目标和验收

- **能同台竞争**：同一章节配置、同预算下，双足对履带、双足对四足的胜率都在 40～60%（astra 用对打统计，样本量和种子写进报告）。
- **赢法不一样**：双足靠速度、躲弹、贴身取胜，而不是靠血量和火力。量化指标：双足的被命中率明显低于同价履带（建议 ≤ 70%）。
- **不破坏现有关卡**：现有关卡（序章 3 关、第一章前 3 关）全是履带车，结果应该不变。
- `node tools/evolve-check.js` 通过，无画面模拟没有 NaN，同种子可复现。

## 3. 阶段 1 · 速度档次

**规则（astra，建议）**

- 目标：**任何配置下三档都不重叠**，也就是双足的基础速度高于四足满超速。
- 建议做法：超速上限按底盘分开设，并把双足基础速度调高，履带不动：
  - 双足基础速度 78 → 约 86，超速上限保持 1.25 → 满超速约 107；
  - 四足超速上限 1.25 → 约 1.15 → 满超速约 71；
  - 履带不动（现有关卡全是履带车，不受影响）。
  - 这样双足最慢也比四足最快高约 20%。
- 要在真实战斗里实测平均车速（包含起步、坡、泥地），不能只看纸面。
- 需要检查的连带影响：AI 的瞄准提前量、镜头跟随、撞击伤害（按速度算）、踢击。

**画面（Opus）**

- 双足在约 100 px/s 时，步幅、起伏、远侧腿错位要看着对（`SA.LEGLAB.strideFor`）。快跑时脚下扬尘，落脚喷蒸汽（`true-biped.md` §3 的待做项）。
- 改装台性能单上的速度齿条：三档的差别要一眼看得出。

## 4. 阶段 2 · 下蹲

**规则（astra，建议）**

- 按住 S / ↓ 下蹲，松开起身，下蹲和起身各约 0.25 秒。
- 整车下沉约 1 个子格（24px），腿区受击面减半。命中本来就按炮弹的真实位置判定（`advance` → `cellAt`），平射弹会自然从头顶飞过，不用另外加概率。
- 下蹲用来稳住：在「后仰炮台姿态」的基础上再稳一档（建议静止散布 −25%、后坐位移 −50%）。被撞时不容易被推开（建议击退 −50%）。代价是不能移动、不能踢击。
- 高抛和间接火力不受下蹲影响。下蹲克制直射，怕臼炮，形成克制关系。
- 腿被毁时（跪地）本来就不能走、还能开火，按「强制下蹲但没有稳定加成」处理。

**画面（Opus）**

- 腿姿：膝盖弯曲、胯下沉 24px。六档腿和 9 种唯一腿都要能弯：`legs.js` 的腿函数加一个下蹲参数（0～1）。
- 躯干跟着整体下移（整像素），陀螺仪转稳。蹲到位时膝部喷一口小蒸汽，脚下一圈尘。
- 输入：键盘 S / ↓（按住）；触屏摇杆往下拉。
- 驾驶台加一盏「蹲」指示灯，只在双足车上出现。

## 5. 阶段 3 · 跳跃

**规则（astra，建议）**

- 按 W / ↑：先下蹲约 0.15 秒蓄力，然后起跳。
- **起跳高度由承重余量决定**：总重占承重的比例越低，跳得越高（建议满载约 0.5 格，半载约 1.5 格）。这样机甲小件（§6）省下的重量直接体现在跳跃上。
- 喷汽背包（加压舱装在双足背后，见 `docs/mech-kit-plan.md`）加跳跃高度。
- 空中：
  - 保持起跳时的水平速度，可以小幅调整；
  - 越过泥地、碎木、货箱；
  - 平射弹按真实位置判定，跳起来就能躲开低平的弹；
  - 可以开火，但散布 ×2。
- 落地：短暂颠簸（`jolt`），散布暂时变大。
- 代价：冷却约 3 秒，每跳一次耗一口汽（汽不够就跳得低），防止连跳。
- 不能跳的情况：失衡、胯被毁、腿被毁、下蹲中（要先起身）。
- 实现提示：跳跃是叠加在地形贴地高度 `s.yo` 之上的一段独立竖直位移；落地后交回 `settle`。
- 第一版**不做**跳过对方的车（两车仍然按行碰撞挡住），也不做踩踏伤害，以后再看。

**AI（astra）**

- 现在的 `evadeAction` 只在左 / 右 / 不动里选。扩展成也能选「跳」和「蹲」：预判来弹经过自己时的高度，低平弹就跳，打躯干高度的平射弹就蹲，抛射弹仍然左右躲。
- 各性格用法不同：冲锋型跳着接近，炮台型蹲着打。
- 进化生成器和无画面模拟都要支持，同种子可复现。

**画面（Opus）**

- 起跳：蓄力下蹲 → 腿蹬直 → 脚底喷一大口白汽；装了喷汽背包时，背后喷管也喷。
- 空中：腿收起（膝盖上提），远侧腿错开。**地面上画一个跟着车走的影子**，让人看得出离地多高。
- 落地：震屏、扬尘、脚下蒸汽，躯干往下压一下再回弹。
- 镜头只跟水平移动，跳起来时不跟着上下晃。
- 驾驶台：一盏「跳」的冷却灯（或一根气压针）。
- 教学：双足第一次出战时，用可配置的教学提示讲下蹲和跳跃（不做常驻提示，见战斗界面规则）。

## 6. 阶段 4 · 双足骑士（机甲套件 / 高密度小件）

可以和阶段 1～3 并行：造型探索不依赖规则。

**现状**

- `docs/mech-kit-plan.md` v0.2 的盘点仍然有效：用现有车用件凑齐 6 个功能位，就吃掉承重的八成。目标是用机甲版小件凑齐 6 个功能位时只占承重的 50～60%。
- 造型 v4（09-25 子格套件，加上肩甲、背负锅炉、背水罐、喷汽背包、腕枪臂）在 `tools/archive/mech-kit-v4.*`。09-30 战斗界面插队时搁置了，**还没给用户审查**。

**步骤**

1. Opus：把 v4 搬回「当前开发」页，补上下蹲和跳跃姿态下手臂、背包的样子，交用户审查。
2. 用户挑定每件的造型。
3. astra 做规则和数据：
   - 手臂类新模块（盾臂、格斗臂、锤臂 / 剑臂、臂炮、腕枪臂）的数据和附加层规则，见 `docs/mech-kit-plan.md` §4 的五条；
   - 现有小件装在双足上换成机甲外观的标记：头盔 = 1×1 驾驶舱，肩甲 = 躯干上角的甲片，背负锅炉 = 躯干后一列的竖式锅炉，背水罐 = 小水罐，喷汽背包 = 加压舱。
4. Opus：造型进游戏（`module-art.js` / `sprites.js`），改装台里显示机甲外观预览。
5. 定价思路（astra 定）：机甲小件**按重量算更强，但更贵**（价格、修理费）。双足缺的是承重，履带缺的是格位和钱，两边的最优零件不一样，路线自然分开。

## 7. 排在后面（已认可）

- **腿型分化**：9 种唯一腿分轻、重两类。除了速度、闪避、承重，还带不同的跳跃高度和下蹲稳定性：轻腿（高跷、板簧跑刃、缩放仪腿）跳得高；重腿（裙甲堡、蒸汽人、圣堂骑士腿）蹲得稳，能扛大炮。
- **双足软超载**：双足可以超载到约 130%，代价是速度、晃动和平衡容差，而且**超载时不能跳**。
