## 0. 一句话

**开车出门，一路往右冲；撞碎挡路的东西，打退拦路的车；收煤、收物资、接难民，进遗迹找新装备；到终点或者见好就收，回院子清点、改车，再出发。**

和现在的区别：

| | 竞技场（现在） | 出征（样板） |
|---|---|---|
| 一局是什么 | 一对一决斗，约 3 分钟 | 一条卷轴路线，4～6 分钟，路上有几场遭遇 |
| 胜负 | 打掉对方驾驶舱 | 走多远、带回多少 |
| 撞击 | 车对车，伤害要平衡 | 撞杂物是爽点；撞车照旧要平衡 |
| 构筑取舍 | 火力 / 装甲 / 散热 | 再加上**煤（走多远）**和**货位（带多少）** |
| 换车 | 很少需要 | 看路线地形挑蓝图 |

## 2. 核心循环

```
院子（基地）── 车间改装 / 蓝图库换车 ── 出征黑板：选路线、看地形、装煤
   ↑                                               ↓
清点收获（物资→钱、难民、遗迹件）           卷轴路线（一路往右）
   ↑                                               ↓
到终点坐运煤车回家 / 中途拉汽笛返航 / 煤尽抛锚被拖回 / 被打爆被拖回
```

三种紧张感，都来自车上的格子：

- **煤**：决定能走多远。煤仓占格子、占重量。
- **货位**：决定能带回多少。货箱占格子、占重量，装满了更重，开得更慢、烧煤更多。
- **耐久**：决定回不回得来。被打爆就丢掉车上的货。

**见好就收**是核心取舍：越往后东西越好，可是煤越少、车越破；被打爆就什么都带不回来。

## 3. 新概念

### 3.1 煤炭

- **每台锅炉自带一个小煤斗**（新字段，例如竖式锅炉 / 燃煤锅炉 / 大型锅炉各带一斗）；**煤仓**是新模块，能多装煤。
- **烧煤**按锅炉实际输出的功率算：行驶、开火、撞锤都耗；站着不动只烧一点点。车越重，行驶耗能越高，烧煤也越快（现有动力公式已经有「每吨 0.3」）。
- **煤烧完**：锅炉只剩余温，供给降到很低（建议 20%），车只能慢慢挪；停稳几秒就算**抛锚**（§3.5）。
- **路上补煤**：路边的**煤堆**，开过去自动铲上车（煤仓满了就铲不上）。
- **煤和水分开管**：水还是管战斗里的热量（现有规则）；煤管行程。**风险**：一条 4～6 分钟的路线可能会把现在为 3 分钟决斗设计的水烧干。astra 先测；如果水不够，路线上放**水塔**补水，或者不打仗时少耗水（由 astra 定）。
- 样板阶段**每次出发免费装满**，不做煤的经济。

### 3.2 货箱

- **货箱**是新模块，提供「货位」。建议两种：**大货箱 2×2（4 位）**、**小货箱 1×1（1 位）**。没装货箱时，驾驶舱顶上能捆 1 位。
- 一份物资、一家难民、一件遗迹件，各占 1 位。
- **每装 1 位加重**（建议 +80 kg）：装满了会变慢、烧煤更多。
- **难民坐在货箱上**，画面上看得见（小碳球人）；物资堆在货箱里，越装越满。
- **货箱被打坏**：里面的东西掉在原地，变成路上的拾取物，可以停车再捡（还有货位的话）。
- 货箱的外观有三套方案，等用户挑（§7 V0，「当前开发」页）。

### 3.3 路线上的东西

| 东西 | 怎么处理 | 说明 |
|---|---|---|
| 木箱、栅栏、废车壳 | 撞碎或打碎 | 现有货箱障碍的推广；撞碎会拖慢一点（现有规则） |
| 煤堆 | **慢行**开过去才铲得上 | 补煤 |
| 物资箱 | **慢行**开过去才捡得到 | 占 1 货位 |
| 难民 | **要停车**：在旁边停稳 1.5 秒才上车 | 占 1 货位；货位满了就接不了，这是取舍 |
| 水塔 | 停在下面自动补水 | 只在样板测出水不够时才放 |
| 掠夺者路障 | 撞开或打碎（有耐久） | 遭遇点的车守在路障前；复用场地路障的画法 |
| 遗迹门 | 打碎或撞开（耐久高） | 门后有一个遗迹箱，里面是一件新装备 |
| 终点站台 | 开到就结束 | 坐运煤小火车回家 |

**捡东西要减速**：车速低于「慢行」（建议最高速的 1/3）时，开过煤堆、物资箱、残骸才捡得到；全速冲过去就错过。路只有一条，如果开过去就自动捡，货位会被最先碰到的东西占满，玩家没得挑。这样「冲」和「捡」本身就是取舍。货位满了以后想换更好的东西，要能扔掉一件（排在样板之后）。

### 3.4 遭遇

- 战斗引擎现在只支持**一对一**，样板就**一次只来一辆**：车头开过触发点，敌车从右边开进画面，或者本来就守在路障前。
- **敌车不会无限后退**：每场遭遇有右边界（路障或者拴绳范围），风筝型的车退到边界就只能打。现在的 `B.bounds` 和路障画法可以复用。
- **打赢**（击毁或接受投降）：残骸留在路上，变成一堆可以捡的物资（「拆零件」）。路障还在的话要撞开。
- 投降照旧（现有规则）。
- 敌车**复用现有的关卡车**，换个名字（§5）。路线里不写台词，只在敌车出场时挂一次名牌（台词以后由用户写）。

### 3.5 回家和结算

| 怎么结束 | 货 | 说明 |
|---|---|---|
| 开到终点站台 | 全带回 + 终点那堆物资 | 坐运煤小火车回家 |
| 中途拉汽笛返航 | 全带回 | 救援车拖回；样板阶段不收费 |
| 煤尽抛锚 | 丢一半 | 停稳几秒后自动拖回 |
| 被打爆（驾驶舱全毁 / 烧干） | 全丢 | 车被拖回；遗迹件也丢 |

- 车的损伤照常带回，回车间按现有规则修。
- 结算（样板）：**物资 → 钱**；**难民 → 人数**（存档计数，样板只显示，以后给基地加用途）；**遗迹件 → 进库存**。
- 返航不需要真的开回去（开回头路太无聊），统一画成被拖回 / 坐火车回。

### 3.6 基地和车间（复用）

- **院子就是基地**；出征的入口拉下一块「出征黑板」（和出战黑板同一套画法）：路线图、地形提示（例如「泥地多：履带吃香，双足吃亏」）、车况、煤量和货位、出发拉杆。
- **车间照旧**：改装、修理、蓝图库换车。按路线地形换车就靠蓝图库。
- 回来时院子里卸货：箱子堆在院子里，难民站到院子一角，黑板上清点收获。

### 3.7 地形和换车

- 样板路线 1 混了平地、木箱、土坡和一大片泥地，履带、四足、双足各有长处短处。
- 以后的路线按地形做出差异，例如矮墙要双足跳过去（需要新规则，排在后面），长泥地要履带，碎石陡坡四足稳。

## 4. 样板路线 1：铁匠铺 → 旧煤场

总长约 **7680 px（6 屏）**。纯开车用时：履带（48 px/s）约 160 秒、四足（62）约 125 秒、双足（90）约 85 秒；加上 3 场遭遇，整趟 4～6 分钟。

| 段 | x 范围 | 地形 | 东西 | 遭遇 | 用意 |
|---|---|---|---|---|---|
| 0 院门 | 0～640 | 平地 | 出发路牌 | — | 起步，看一眼煤表 |
| 1 碎石路 | 640～1920 | 平地 | 木箱 ×3（900、1250、1700），煤堆（1500） | — | 学会「撞过去」，捡第一堆煤 |
| 2 拦路 | 1920～2560 | 平地 | 掠夺者路障（2520） | **E1 拾荒小车** 守在路障前 | 第一场，弱，可以直接顶翻 |
| 3 土坡 · 难民 | 2560～3840 | 土坡（中心 3000，宽 360，高 44） | 物资箱（2800）、难民一家（3400，路牌下）、物资箱（3650） | — | 第一次「停车接人」，上下坡 |
| 4 泥洼 | 3840～4800 | 泥地 3900～4600 | 物资箱（4300，泥地正中） | **E2 铁皮罐头** 守在泥地对岸（约 4750），用迫击炮压着打 | 泥地里挨炮：履带吃香，双足吃亏；要不要下泥地捡那箱物资 |
| 5 水泵站遗迹 | 4800～5760 | 平地，一道小坡（中心 5200，宽 200，高 20） | 水塔（5050，按需），**遗迹门**（5550，耐久高），遗迹箱 | — | 停车破门、补水；喘口气 |
| 6 煤场前哨 | 5760～7040 | 平地 + 木箱堆 | 难民一家（6000），煤堆（6300），木箱 ×2（6500、6560），掠夺者路障（7000） | **E3 推土机** 从右边冲过来 | 最强的一场，铲斗对冲；货位满了的话要取舍 |
| 7 旧煤场 | 7040～7680 | 平地 | 终点站台（7400），大物资堆 | — | 抵达，坐运煤小火车回家 |

**煤的设计意图**（给 astra 调数时参考）：

- 满煤出发，不绕不停直开到终点，剩约 30%。
- 每场遭遇大约多耗 10%；路上两堆煤各补约 15%。
- 打得拖拉、在泥里来回挪，会开始担心煤；但样板路线不应该让正常玩家在终点前抛锚。

**货位的设计意图**：

- 路上能捡的：物资箱 ×3（2800、3650、4300）+ 残骸拆件 ×3 + 难民 ×2 + 遗迹件 ×1，一共 9 份，远多于一个大货箱（4 位），逼玩家挑。
- 终点大物资堆不占货位（直接算进结算），奖励开到底的玩家。

## 5. 范例敌人（复用现有关卡车）

| 编号 | 路线里的名字 | 复用 | 性格 | 特点 |
|---|---|---|---|---|
| E1 | 拾荒小车 | `0:0`「天降横财？」的车（头盔 + 竖式锅炉 + 车载机枪 + 履带） | rookie，准度低 | 很弱，教玩家「顶过去」 |
| E2 | 铁皮罐头 | `1:0`「铁皮罐头」（小臼炮 + 甲片） | turtle，守着不动 | 隔着泥地用迫击炮压人 |

| 备选 | 双管哨兵 | `1:1`「兄弟齐心」（双机枪，风筝） | kite | 测敌车不能无限后退 |
| 备选 | 独角兽 | `1:5`「独角兽」（撞角 + 铲斗） | rush | 撞角冲锋，测撞角伤害 |

- 以后的杂兵（不在样板里）：固定的发条步哨炮台、会滚过来的炸药桶车、成群的小拾荒车。它们要引擎支持一对多，见 §9 阶段 2。

## 6. 规则改动（astra）

| # | 内容 | 要点 |
|---|---|---|
| A1 | 路线数据 | 新增路线数据（放 `config/content.json` 的新键或单独文件，由 astra 定）。格式建议见 §8.1；先录入样板路线 1 |
| A2 | 长地形 | `B.ter` 支持任意长度（`len`）；`groundAt` / `crateAt` / 泥地 / 土坡在 0～len 都生效（现在只在 0～1280）；木箱推广成「可撞碎的东西」，带种类 |
| A3 | 路线模式的战斗循环 | `opts.mode = 'route'`：不计时、不判超时；敌车按触发点**接力出场**，同一时间只有一辆（引擎仍是一对一）；没有敌车时也能正常运行；敌车有右边界（拴绳）；击毁或投降后残骸留在路上变成拾取物，路线继续 |
| A4 | 镜头 | 没有敌车时跟着玩家，往前多看一段；有敌车时沿用现在框住两车的做法。镜头状态仍在 `battle.js`（炮弹出界判定依赖它） |
| A5 | 煤炭 | 锅炉加煤斗容量字段；煤仓模块；按实际输出功率烧煤；煤尽后供给降到很低；拾取补煤 |
| A6 | 货箱 | 货箱模块的货位字段；`B.p` 上的货物清单；每位加重；货箱被毁时货物掉到路上变成拾取物 |
| A7 | 拾取和物件 | 煤堆 / 物资箱 / 难民（要停车）/ 水塔 / 掠夺者路障 / 遗迹门 + 遗迹箱 / 终点站台；拾取判定和事件（§8.3） |
| A8 | 结束和结算 | §3.5 的四种结束；结算结果对象（§8.4）；存档新字段（建议 `d.route`：难民人数、出征次数、各路线最远距离和是否通关、遗迹是否已拿）；物资折钱、遗迹件进库存 |
| A9 | 新模块数据 | 大货箱、小货箱、煤仓：尺寸、价格、耐久、重量、容量；样板阶段直接给玩家或在商店能买（由 astra 定）。外观先用 `art` 借形占位，等 Opus 的造型定稿 |
| A10 | 无画面模拟 | `SA.Route.simulate({ route, vehicle, seed })`，由 AI 替玩家开车，供 MCP 回归和调煤量；跑 20 个种子无报错、无 NaN |
| A11 | 入口接口 | `SA.Route.list()`、`SA.Route.start(id)`（开发者控制台也能调）、`SA.Route.settle(result)`；占位画面先跑通，再交给 Opus 接画面 |
| A12 | 水 | 测一条 4～6 分钟的路线会不会把水烧干；不够的话用水塔或「不打仗少耗水」解决，由 astra 定 |

**试玩反馈（用户转述）**：撞角伤害过高、近战算法夸张。改不改、改到什么程度由用户和 astra 定。建议：**撞杂物**（木箱、路障、遗迹门、以后的杂兵）不走车对车的撞击公式，两边分开调，路线的爽感和决斗的平衡互不牵制。

## 12. 小机械：撞碎了能带回一点金属（2026-10-06 用户提出）

用户：路上加**被撞碎的小机械**，撞碎了**能带回来一点金属**。这正好给「开足马力冲过去」一个回报：慢下来捡物资，冲过去撞机械。

### 12.1 设计（建议，数值由 astra 定）

| 种类（暂名） | 样子 | 行为 | 怎么对付 |
|---|---|---|---|
| 拾荒爬车 | 巴掌大的小履带车，前面一只抓钳，背着一小筐破烂 | 慢慢朝你爬过来，贴上车头就用钳子啃最前面的模块（伤害很小） | 随便撞，一撞就碎 |
| 滚桶炸弹 | 拴着引信、冒烟的旧锅炉桶，在坡上自己往下滚 | 沿坡滚向你，碰到车就炸（溅射伤害）；平地上滚得慢 | 远远一炮打掉最好；硬撞也能撞碎，但会炸 |
| 发条步兵 | 一队 3～5 个上发条的铁皮兵，背后钥匙在转 | 排成一排往前走，停下来举小火枪齐射（很弱） | 冲过去一排全撞碎，最爽 |
| 步哨炮车 | 两个轮子的小炮车，炮口朝你 | 原地不动，隔一会儿打一发小炮弹 | 比较结实，要打几下或用撞角撞 |

- 美术规范照旧：都是机器（维多利亚、工业、一战风格），不做生物；小机械比车小得多（一辆车 6～8 格宽，小机械 1～2 格）。
- **金属**：撞碎或打碎都会掉一点金属。建议**不占货位、也不用减速**：碎片自动飞上车。这样它和要减速才捡得到的物资、要停车才接得上的难民，是三种不同的收获。回院子单独记一行「金属」，样板阶段先折成钱，以后再定用途（例如修理、升级材料）。
- 有没有机械、有几个，按路段配置（例如坡顶放滚桶，谷底放拾荒爬车，上山路放发条步兵）。

### 12.2 分工

- **astra**：引擎现在是一对一的车战，小机械要做成独立的轻量单位（不是整车）：`B.mobs[]`。需要它们的移动、贴车伤害、被炮弹打中、被撞碎的判定（建议按相对速度和撞击件判断「一撞就碎」），掉金属，结果里加 `metal`，以及入档。
- **Opus**：四种机械的造型、走动 / 滚动帧、被撞碎时散架（齿轮、铁片、弹簧飞出去）、金属碎片飞上车、清点黑板的金属行；先在「当前开发」出稿给用户挑。

### 12.3 接口建议

- `B.mobs[]`：`{ id, kind, x, hp, max, dir, state: 'walk' | 'attack' | 'fuse' | 'dead', t }`（地面高度画面层自己取）。
- 事件：`mob-hit { id, kind, x, y }`、`mob-break { id, kind, x, y, by: 'ram' | 'shot' | 'blast', metal }`、`mob-fire { id, kind, x, y }`、`mob-blast { x, y, r }`（滚桶爆炸）。
- `B.route.metal`（这一趟收了多少），结果 `result.metal`。

## 13. 起伏地形：参考真实世界，换成 19 世纪（2026-10-06 用户提出）

### 13.1 参考：英格兰「黑乡」（Black Country）

伯明翰西北的黑乡是 19 世纪真正的「工业废土」：白天被煤烟熏黑、夜里被高炉映红；矿渣堆、煤渣堤到处都是，运河和铁路纵横交错，废弃的抽水机房和矿井架随处可见。它很适合当「废土英格兰」。

**真实地形剖面**：用欧洲 25 m 数字高程模型（EU-DEM，经 OpenTopoData 取样）沿一条真实的路取样 100 个点：

**达德利城堡岭 → 内瑟顿 → 风车端（运河谷底）→ 特纳山（罗利山顶）→ 罗利里吉斯**
