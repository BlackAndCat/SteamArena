# 蒸汽竞技场 · 材质与模块造型规则 v1

> 2026-09-27 · Opus。由材质语言 v2（`tools/material-lab.html`）和直射火炮高阶造型（`tools/cannon-lab.html`）两轮探索、用户多轮整改意见总结而来。
> 以后画任何模块的六档外观（T1 黄铜 → T6 以太合金）都按这份做；和 `docs/art-style.md`、`docs/art-direction.md` 冲突时以本文件为准。
> 已落地：六档材质（`js/palette.js` 的 `SA.PAL.mat` + `js/sprites.js` 的 `decorate`）、直射火炮六档造型（`sprites.js` 的 `DRAW.cannon` / `OVER.cannon`、公共零件 `PART`）；中炮、小炮六档（`DRAW.cannon_m` / `OVER.cannon_m`、`DRAW.cannon_s`、`DRAW.side_cannon` / `OVER.side_cannon`、`DRAW.cannon_heavy` / `OVER` / `UNDER.cannon_heavy`，样机 `tools/gun-family-lab.html`）。

---

## 0. 一句话

**材料靠颜色和做工区分，档位靠「形体两次跃迁 + 散热口 + 一两件固定位置的零件」区分；全部直线、全部克制、全部蒸汽朋克。**

## 2. 材质

### 2.1 六档（定稿）

| 档 | 材料 | 做法 |
|---|---|---|
| T1 | 黄铜 | AAP-64（Adigun A. Polack）旧黄铜色阶，饱和度 ×1.45：暗部红褐 → 亮部金黄；柔和高光 |
| T2 | 熟铁 | 暗、暖灰、哑光；锻打麻点（只暗一阶，稀疏） |
| T3 | 钢 | 淡青钢（青色饱和度约 8%）+ 稀疏花纹板（8px 一格、每格一道 2px 斜纹）；锐利亮边 |
| T4 | 镀镍 | 象牙白瓷漆 + 淡金饰件 |
| T5 | 乌兹钢 | 暗钢边 + 布伦瑞克绿瓷漆 |
| T6 | 以太合金 | 海军蓝瓷漆 |

- **黄铜色阶是所有金属色阶的范本**：色相随明度偏移（暗部偏红 / 偏冷，亮部偏黄 / 偏暖）。单一色相再压低饱和度会发灰、没有材料味。
- 描线（离外沿 3px 的细线）**已关掉**：它让高档显得复杂、「高级」。代码还支持，`SA.PAL.mat[材料].line` 填颜色即可恢复。

### 2.2 怎么上材质（代码已实现，画新模块不用管）

1. **画模块只用原画的冷蓝铁**（`SA.PAL.iron` / `dark` / `rust`）+ 黄铜 / 语义色；冷蓝铁是所有材料的「源色」。
2. 渲染时金属像素**按阶替换**成材料色（不混色、不产生调色板外的脏色）；黄铜饰件、炉火、水、玻璃、皮革、驾驶员保持原色。
3. 瓷漆只刷模块大面（固有色和亮侧两阶），受光的亮边和斜面仍露金属。
4. 纹理只改明度一阶、只落在平整面，每 4×4 至多一个细节；不碰描边和亮边。
5. **不发光**。唯一发光的仍然只有炉火和炮口闪光。

### 2.3 颜色的上限

- 金属固有色饱和度一般 ≤ 15%；瓷漆可以更饱和，但必须是深色（明度低）的维多利亚机车漆：布伦瑞克绿、海军蓝、象牙白、深红……
- 高饱和色只留给语义色（炉火、水、压力表绿）和 UI 的品质色块。

### 2.4 否掉的做法（不要再用）

- 整体染成高饱和材料色（旧装饰层的钢蓝、乌兹钢紫、以太青）；
- 满铺图案：镀镍斜条纹、乌兹钢大波浪、以太发光脉络；密到像噪点的大马士革 / 机刻纹；
- 彩色晕染、回火虹彩（油光感）、零散杂色斑（脏）；
- 只染亮边、只染暗部或亮部（看不出来）；
- 发光（以太的发光铆钉也不行）。

## 3. 造型

### 3.1 总则

- **只用直线和直角。** 高档不出现圆顶、弧形炮廓、刻槽、喇叭口、流线。圆只留给本来就圆的小零件（耳轴、压力表、铆钉头）。
- **不靠堆复杂度升级。** 高档靠「形体跃迁 + 更多散热口 + 一两件零件」，不靠更多线条和细节。
- **1× 可读。** 每一档缩到实机大小都要一眼认出是什么模块；功能件（炮口、炉门、水窗）的形状必须一眼能懂。

### 3.2 形体只跃迁两次

| 档 | 形体 |
|---|---|
| T1～T2 | 原画的方形（直射火炮：方指挥塔） |
| T3～T4 | 仍然方正，但更「厚」一级（直射火炮：方平顶炮廓 + 方舱盖） |
| T5～T6 | 自带**斜向板**（直射火炮：炮廓前沿向后倾），这是高档唯一的斜线 |

同一形体里，两档之间只靠材料颜色、散热口、零件区分。

### 3.3 散热口是档位语言

| 档 | 散热口 |
|---|---|
| T1～T2 | 两道横槽 |
| T3～T4 | 三道横槽 |
| T5 | 双列横槽 |
| T6 | 斜百叶 |

画法：一道暗线 + 下面一道亮线（有进深），放在散热区里，任何零件不得压上去。

### 3.4 功能件

- 炮管随形体跃迁换：T1～2 素管两道黄铜箍 + 方制退器；T3～4 炮尾套筒 + 一道箍 + **连在一起的**阶梯式方制退器；T5～6 粗炮身 + 三道铁箍 + 大方制退器。
- 炮口末端位置各档不变（`piv` / `blen`），否则炮弹出膛位置对不上。

### 3.5 1×1 小模块：只靠剪影

- 1×1（24×24）**不放身份件**：不放铆钉、散热口、压力表、铭牌、包角铁。塞零件只会增加视觉压力、降低识别度。
- **主体撑满格子**：不要把主体画小、留出大片空底（小炮 v2 上方 1/3 空着，被否）。
- 档位只靠**轮廓**跃迁（仍在 T3、T5）：例如小炮 = 铸造瓶身 → 方套箱 → 斜肩套箱；材料只靠颜色。
- 最多保留一两样结构件（小炮：耳轴方形固定螺栓 + 一道黄铜箍），它们属于结构，不是装饰。
- 2×1 及以上才按 §4、§5 放零件，并且按比例减半（中炮不放铭牌，只放直径 7 的小压力表）。

## 4. 零件库（`js/sprites.js` 的 `PART`，可复用）

| 零件 | 尺寸 | 颜色 | 何时出现 | 画在哪一步 |
|---|---|---|---|---|
| 散热口 `vents` | 横槽 12 宽 / 双列 6 宽 / 百叶 | 铁（跟材料） | 全档（数量、排法按 §3.3） | DRAW |
| 包角铁 `corner` | 5×5 L 形 + 1 颗钉 | 暗铁（跟材料） | 钢起 | DRAW |
| 接缝铆钉 `seam` / `rivet` | 每颗 3×3 | T1～3 黄铜，镀镍起钢质淡青 | 全档，数量 2 → 3 → 4 | OVER（固定色） |
| 珐琅铭牌 `plate` | 10×6 | 黄铜边 + 深色底 + 黄铜刻字 | 镀镍起 | OVER |
| 压力表 `gauge` | 直径 11 | 黄铜圈 + 白表盘 + 绿区 + 指针 | 镀镍起 | OVER |
| 铁箍 | 3×高 | 铁（跟材料） | 炮身，T5～6 | DRAW |

| 对称齿轮 `gear` | 迷你 D8 / 小 D10 / 中 D14 / 大 D20 / 超大 D24 / 巨型 D32 | 真黄铜（`GEAR_RAMP`：黄铜蓝通道 ±1，材质处理不认，所以固定） | 重炮、臼炮 | DRAW 的任何层次 |
| 预制齿轮组 `gearSet` | 超大在后，大 → 中 → 小依次叠在前面咬合 | 同上 | 重炮 | UNDER |
| 传动杆 `shaft` + 轴套 `collar`、连杆 `link` | 2px 铁杆 / 黄铜销 | 铁（跟材料） | 配齿轮用 | DRAW |

备用（样机里有，暂未采用）：徽记、顶饰、檐口线脚。

**齿轮的画法**（用户整改：要大、镂空、有力；颜色纯、不杂；外形完美对称、禁止杂边和奇怪的突起）：直径取偶数、圆心在像素角上，只算 1/8 扇区再镜像成 8 份（像素级对称）；矩形齿、齿数是 4 的倍数；辐条沿坐标轴或对角线；**纯色做底，不描深色边**；金属感只靠本色的邻阶：朝左上的边亮一阶、朝右下的边暗一阶（斜面），轮缘左上一段弧亮、右下一段弧暗，轮毂亮一阶带高光点；最后面的超大齿轮本色暗一阶；转动只在 4 个对称帧之间切换（齿相位 0 / 半齿 × 辐条正 / 斜）。齿轮不做装饰堆砌：一组齿轮 + 传动杆就够，其余底座装饰全去掉（重炮 v3 的铜管、阀门、减重窗、手轮都被否）。

**三步画法**：跟材料换色的铁件在 `DRAW[id]` 里画；颜色必须固定的身份件（铆钉、铭牌、压力表）在 `OVER[id]` 里画；颜色固定、又必须在最后面的背景件（齿轮组）在 `UNDER[id]` 里画（destination-over）——渲染管线是 `DRAW → 改装挂件 → 材质处理 → OVER → UNDER`。这样铭牌永远不会和底色同色，铆钉颜色由档位决定。

## 5. 排布规则（立面分区）

每个模块先找出它的「立面」——露在外面、没有被炮组 / 炉门 / 水窗占住的那块平面，然后从上到下分区，**每区只放一类东西**：

1. **接缝线**：铆钉只打在上下两块板的接缝下沿，等距一排，两端让出包角位。
2. **散热区**：散热口独占，不压任何零件。
3. **铭牌区**：散热区正下方、腰线之上，和散热口左对齐。
4. **包角位**：立面外沿露出来的角（直射火炮是炮座的左上、左下、右下三个角）。
5. **表位**：上层结构（炮廓 / 舱顶）左侧那块平面；原来在那里的观察缝挪到右边。
6. **功能区**：炮组、炉门、水窗、驾驶舱舷窗——永远不放零件。

- 零件之间、零件和散热口 / 观察缝之间至少空 **1 像素**。
- 分区坐标写成模块自己的常量（例：`CANNON_ZONE`），不在绘制代码里散落魔法数字。

直射火炮的分区（模块内坐标）：接缝铆钉 y 18～20、x 10～25；散热区 x 7、y 22～30；铭牌 x 7、y 32～37；表位中心 (11, 11)；包角 (3,16) / (3,40) / (40,40)。

## 7. 流程与验收

1. **先做样机**（`tools/` 下，登记进样机馆 `tools/labs.js`），和游戏现状并排；六档一行、附 1× 实机大小、放进车体。
2. 用户确认后才写进游戏；写进游戏后用 `tools/spritesheet.html` 的材料矩阵核对和样机一致。
3. 验收：
   - [ ] 1×：一眼认得出模块和功能件
   - [ ] 六档并排：每档都能和相邻档区分，但仍是同一个模块
   - [ ] 零件都在分区里，没有压散热口 / 观察缝，间隔 ≥ 1px
   - [ ] 只有直线（小圆零件除外）；没有发光
   - [ ] 灰度下六档材料仍分得开

## 8. 下一步：火炮家族再设计

按本规则依次做：**中炮（2×1）✅ → 小炮（1×1，卡隆短炮）✅ → 侧炮 ✅ → 重炮（改成横躺 3×2）✅ → 臼炮 ✅→ 巨炮（4×4）**。要点：

- 每个模块先画出自己的立面分区（`*_ZONE`）；小模块立面小，散热口和零件按比例减半；**1×1 不放零件，只靠剪影（§3.5）**。
- 形体跃迁、散热口表、铆钉颜色、零件出现档位全部沿用本文件，保证同一档的火炮家族一眼是一套。
- 小炮以用户满意的卡隆短炮为骨架；中炮保留横躺长炮的剪影；重炮 / 巨炮可以多一个立面（多层），但每层仍按同一套分区。
