# 战役方向 · 探索稿

> 2026-09-26 · v0.1。记录用户和 Claude 讨论出来的战役与成长方向。
> **这是探索稿，不是定稿。** 实际能做的内容比这里多，途中会不断小修小改。标"已定"的是用户明确拍板的；其余是方向，astra 和 Opus 按它实现第一版，但要做成**数据驱动、方便随时改**的形式，不要写死。
> 分工：§9 后端归 astra，§10 视觉归 Opus（见 `docs/collab.md`）。

## 0. 核心体验

**每章一个主题，引导玩家面对越来越酷炫的敌人，然后发现自己也可以变得这么酷炫。**

- 敌人先示范，玩家再拿到：带模块奖励的对手，车上就装着这件模块（`docs/evolve-plan.md` §7.6）。
- 每章都让上一章的主流打法不再那么好用，逼玩家换思路（§2 克制链）。
- 每一关只解锁 1～2 样新东西，避免思考负担过重。
- "新武器"和"非武器提升"交替出现，比如蓄压罐带来爆发。
- **第四章 Boss 结束时开放大部分装备**；第五章主要放唯一件。
- 每章的精英关加 Boss 关可以超过 3 关。

## 1. 章节主题（探索）

| 章 | 主题 | 敌人 / Boss 的样子 | 玩家拿到的 |
|---|---|---|---|
| 序章 | 学会开车 | 练习车 | **前几关就给铲斗**（已定方向）：前期没有好炮，瞄准很折磨人，玩家会自然选择动力强劲的近战车 |
| 一章 | 推与挡 | 撞击车、薄甲车。**Boss：车头厚重装甲，用更高位置的火炮或侧炮往下打**，专门克制纯近战 | 赢 Boss 拿到侧炮和侧挂层 |
| 二章 | 抛射 | 玩家用"侧炮 + 近战"，但很快会遇上臼炮。**Boss：前装甲厚重，后面一排臼炮，加联合驾驶舱** | 高抛类武器、联合驾驶舱 |
| 三章 | 缠斗 | 撞角、鱼叉、蒸汽喷射器狂轰滥炸 | 撞角、鱼叉、蒸汽喷射器等 |
| 四章 | **按下不表**（已定） | 测试不够，现在规定属于自讨苦吃，等前几章做出来再定 | 开放剩余的大部分装备 |
| 五章 | 综合考试 | 综合前几章的主题；宿敌玛莎复仇；女王号 | 唯一件（巨炮等） |

## 2. 克制链

| 阶段 | 敌人的防御 | 有效解法 | 这个解法的代价 |
|---|---|---|---|
| 前期 | 薄甲片，机枪能打碎 | 铲斗贴近 + 机枪洗脸 | 几乎没有 |
| 中期 | 更厚的装甲：机枪、侧炮打上去**弹开** | 近战硬顶 | **反震**伤到自己的撞击件，打一场修理费不少 |
| 后期 | 厚甲 + 反震 | 装上主炮，更详细地规划火力 | 要瞄准，要算动力和热量 |

**旧解法不能彻底作废**：机枪打没装甲的锅炉、水箱、驾驶舱仍然好用；近战配鱼叉（拉过来就撞）也应该划算。

**需要注意**：三章的主题是缠斗，同时近战又因为反震变贵。敌人不付修理费、玩家要付，要避免"敌人用得很爽、玩家拿到却不想用"。可以考虑让被鱼叉拉过来的撞击不需要助跑，或者反震减半。

## 3. 跳弹（穿深 vs 装甲厚度）

用来让机枪和侧炮成为"补强"而不是"主力"，同时让"打不中"**有看得见的原因**，而不是明明在弹道上却凭空落空。

- 武器新增**穿深**，装甲新增**厚度**（可以从现有护甲值演化出来）。
- 穿深不够：有一定概率弹开，伤害近乎为零；穿深够：照常按护甲减伤。
- **装甲厚度随材料放大，穿深不随材料放大**：装甲越往后越难打穿，只有大口径炮能稳定打穿，逼玩家上主炮。
- 前期甲片耐久低，会被机枪打碎。
- **侧炮**：降低威力，并让它对装甲容易弹开（已定方向）。
- 弹开要有反馈：火花、"弹开"字样（画面归 Opus）。

## 4. 反震

- 撞击时自己的撞击面也受伤。现在已有 `RAM_SELF`（反作用伤害占造成伤害的 30%），按克制链的需要调整。
- 目标：中期起，靠近战硬顶厚甲会明显伤到自己，再通过修理费（§5）体现成本。

## 5. 修理费：按部件设比例（已定）

**越复杂精密的东西，维修起来越贵。** 这样低等级、便宜的装备一直有用武之地；高级装备打一场可能要修几千块钱，赚的钱全都赔进去。

- 每个模块有自己的修理费比例，修理费 = 模块总价值（含材料升级和改装）× 修理费比例 × 损伤比例。
- 用户给出的参考值：

| 模块 | 修理费比例 |
|---|---|
| 铁板、甲片、装甲 | 很便宜 |
| 水箱、水罐 | 相对低很多 |
| 铲斗 | 1/8 |
| 蒸汽撞锤 | 1/5 |
| 驾驶舱、锅炉 | 昂贵 |

- 其余模块由 astra 按"越复杂越贵"提议，经系统健康测试和经济模拟验证后交用户批准。
- 现在所有模块统一是原价的 1/20，玩家基本感觉不到修理费，要换掉。

## 6. 唯一件（已定方向）

- **唯一件不只一件**，可以收集多件。
- **双足唯一件**：双足探索期间画出来的、有故事感的设计（熔心龙骑、蒸汽圣骑、钟表巨像等），可以作为散布在 T3～T5 的高级精英或 Boss，赢了拿走它们身上的双足唯一件。
- **用户可能随时按颜值把某个东西抽出来当唯一件**，所以唯一件要做成数据上的一个标记，任何模块都能打上，不要写死在某几件上。
- 建议（待探索）：唯一件要有取舍，不能只是最强，让玩家因为"喜欢它的风格"而换装。例如熔心龙骑自带一点动力但更热、蒸汽圣骑耐久高但慢、钟表巨像极稳但起步慢。
- 哪些腿型留给普通双足的阶段造型、哪些做成唯一件：**还在探索**，等用户决定。

## 7. 支线：竞技场外的遭遇战（已定方向）

- **第二章起就能打**支线，拿特殊件。
- 例子：游荡的蒸汽圣骑。非竞技场、没有观众、没有声望，打完拿到炫酷的双足。玩家甚至可能为了双足的帅气，抛弃原有的履带或四足。
- 支线是可选的，只给非必需的东西（特殊件、唯一件、材料等）。核心武器仍挂在主线必打关上。
- 待探索：出现方式（固定在某章出现 / 在几章之间游荡）、难度（建议比同档 Boss 难一些，因为奖励更好）、战损是否照常带回车间。

## 8. 重打与友谊赛（已定）

- **主线和支线都能打。**
- **友谊赛合并进锦标赛 / 战役列表**，不再单独成为一种比赛：已经打赢的对手（主线和支线的 Boss、精英）可以回去重打，按友谊赛规则——**没有奖励，也没有损失**。
- 目的：让玩家变强以后，体验回去碾压的快感。
- 待定：分享码导入的车在哪里打（建议放进试驾场，或并入同一个列表）。

## 9. 后端工作（astra）

以下是 astra 的范围。机制按本文件实现第一版；具体数值走 `docs/evolve-plan.md` P2 系统健康测试，由用户批准后才改。

| 项 | 内容 |
|---|---|
| K1 跳弹 | 武器穿深、装甲厚度、弹开概率和结算；材料放大厚度、不放大穿深；前期甲片可被机枪打碎；侧炮降低威力并更容易弹开。战斗事件记录里加上"弹开"次数，供表现分和生效统计使用 |
| K2 反震 | 调整 `RAM_SELF` 等撞击自伤规则，满足 §2 的克制链；考虑"鱼叉拉过来的撞击"的例外 |
| K3 修理费 | 每个模块一个修理费比例字段（`modules.js`），替换现在统一的 1/20；用户给的参考值按 §5；其余提议后报批；进经济模拟验证 |
| K4 战役重排 | 按 §0、§1 排出第一版：序章前几关给铲斗；每关 1～2 样解锁；第四章 Boss 后开放大部分装备；第四章内容先保持现状或占位；第五章放唯一件。解锁数据保持数据驱动，方便用户随时改 |
| K5 唯一件 | 数据标记（不可购买、只能缴获、材料固定、每个存档只能拿一次或按用户规则）；任何模块都能被标成唯一件；双足唯一件先按数值取舍做成数据（外观先借形） |
| K6 支线 | 竞技场外的遭遇战：第二章起可打；没有奖金和声望；奖励特殊件 / 唯一件；可选；出现方式先做成可配置的简单版本 |
| K7 重打 | 友谊赛合并进列表：已击败的对手可以重打，无奖励、无损失；移除独立的友谊赛页签（入口先用现有组件，整理交给 Opus） |
| K8 进化生成器联动 | `docs/evolve-plan.md` 的分档约束跟着 K4 的新解锁走；支线对手单独一档目标（暂定：本档 Boss 打它胜率 30%～40%）；唯一件的持有者按"奖励车"规则检查模块确实有作用 |
| K9 早期近战验证 | 系统健康测试里加一项：早期近战车（铲斗 + 动力）对早期对手的胜率和用时，确认"铲斗解法"真的成立 |

**战斗规则冻结点**：K1～K3 属于大的战斗规则改动，要在冻结点之前完成（`docs/evolve-plan.md` §10.5）。
