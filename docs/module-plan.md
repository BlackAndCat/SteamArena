## 0. 已经定下来的决定

1. **不按「模块 × 等级」画图。** 颜色管 6 级（已实现换色），造型只给值得的模块，最多 3 个。
2. **火炮每 2 级换一次外形**：T1–2 / T3–4 / T5–6，T6 在 T5 的造型上加以太发光特效。
3. **火炮家族五档**：小炮 1×1、中炮 2×1（横躺）、现有直射火炮 `cannon` 2×2（保留）、重炮 2×4（T4 起才有）、巨炮 4×4（独一无二的缴获）。
4. **玩家的初始火炮改成 2×1 中炮**（横躺，只占一行）。
5. **驾驶舱统一成 1×1。** 1×2、2×2 的「联合驾驶舱」算换皮：外壳变大，**里面的驾驶员保持 1×1 的大小，不等比放大**。
6. **机枪、臼炮以换皮为主**，再加几件特殊武器。
7. **新模块**：蓄压罐、加压舱（加动力也加产热）、散热片（侧挂，比水罐弱）、冷凝器、火箭架、鱼叉、喷火 / 蒸汽喷射，外加观察镜等 1×1 小部件。
8. **双足行走底盘已经完成**，双足相关的样机和素材全部保留。**真双足规则进游戏**（2026-09-25）：不管底盘多宽都只有一对腿，可以装撞击件和侧炮，高度上限就是改装台 6 层，见 `docs/true-biped.md` §8。
9. **直射火炮 `cannon` 熟铁（T2）起才有**，黄铜阶段没有它，给玩家一个盼头。关卡里黄铜材料的敌车自动换成中炮。
10. **驾驶员人数只决定能多操作几组武器**：全车活着的驾驶员比 1 多几个，就多几组武器由他们自动瞄准开火（2 个驾驶员 = 多 1 组，4 个 = 多 3 组）。1×1 驾驶舱 1 人、1×2 联合驾驶舱 2 人、2×2 联合驾驶舱 4 人。
11. **取消副驾驶**：功能并入驾驶员人数。旧存档、旧分享码里的副驾驶读进来一律换成 2×2 联合驾驶舱。
12. **驾驶舱辅助设备全部改成打得掉的 1×1 实体**（观察镜、装弹机、测距仪、陀螺仪），旧的辅助设备系统删除（2026-09-25）。新模块尺寸保持暂定，现在只做功能，视觉以后再做。
13. **喷火 / 蒸汽喷射是一个模块、两种换皮和特效**，玩法本质都是给对手升温。
14. **功能优先于视觉**：没有专用 `DRAW` 的模块先使用已有精灵借形；模块卡片、数值工具和战斗信息必须显示中文名称，必要时显示「占位 · 模块名」文字。专用像素画、粒子和换皮后补，不能为了等美术推迟玩法、解锁或 Boss 验证。

尺寸都按代码里的「宽 × 高」、以小格（24px）计。

## 1. 分级规则

| 级别 | 造型 | T6 | 用在哪里 |
|---|---|---|---|
| S 唯一 | 1 个，材料固定 | — | 巨炮、Boss 特殊件 |
| A 三形 | T1–2 / T3–4 / T5–6 | 加特效 | 火炮、底盘 |
| A′ 限阶 | 从解锁的那一级开始，每 2 级换一次 | 加特效 | 重炮（T4 起：T4 一个，T5–6 一个） |
| B 两形 | T1–4 / T5–6 | 加特效 | 锅炉、撞击件、火箭架、鱼叉、喷射器、驾驶员换装 |
| C 一形 | 1 个，靠换色和材料装饰层区分 | 装饰层自带 | 其余所有模块，以及全部换皮 |

对玩家就一句话：**「钢开始，火炮和底盘变形；史诗以上，主力件全部变形。」**

画的时候要守住的几条：

- **炮口位置在各阶段之间不变**（`piv` / `blen`），只改炮身、炮箍、炮口装饰，否则炮弹出膛的位置会和画面对不上。
- **底盘骨架不变**：负重轮、链轮、腿长都不动，否则步态、悬挂偏移（`gnd`）和左右连接都要重调。
- **裙板留给改装**（底盘的改装件就叫「加固裙板」），底盘的阶段造型改负重轮、侧框的肋、链轮。
- **24px 的小模块只靠换色区分等级**，这个尺寸上换造型基本看不出来。
- **像素不缩放**：同一家族不同尺寸，靠参数（炮管长短、箱体宽窄、弹鼓数量）画出来，共用零件和阶段挂件。

两个一次做完、所有模块都受益的层：

- **材料装饰层**（6 套，只作用在金属像素上）：黄铜是原画，熟铁是锻打斑点，钢是冷色高光边，镀镍是镜面条纹，乌兹钢是流水花纹，以太是发光纹路。它顺带替掉驾驶舱、锅炉、水箱现在只在四角钉角铁的做法（`markMat`）。
- **改装挂件**：4 种（炮盾、裙板、撞面、附加装甲），每种 3 级逐级加板，挂在模块外侧的挂点上，颜色跟随材料。要适配火炮家族的 5 种尺寸。

### 阶段 0 · 接口与数据（完成）

- **外观阶段**：模块的 `vis` 字段列出从哪几级材料开始换外形，`SA.stageOf(id, mt)` 算出 1~3；精灵缓存键里带 `q.st`，`DRAW[id](x, y, q)` 按 `q.st` 画对应造型（没有多个造型的模块永远是 1，不写进键里）。
- **按占格画**：精灵画布按模块占格放大（`w×24 + 32` × `h×24 + TOP + BOT`），有自己美术的小模块按原生大小贴，借用大模块精灵的暂时缩小（`drawModule` / `modSprite`）；卡片预览 `moduleCanvas` 也按占格放大。
- **最低材料（限阶）**：`minMt` + `lowAlt`。`SA.newCell` 自动补到最低材料；商店按最低材料卖、按那一级的总价值收钱（`SA.buyMt` / `SA.buyPrice`）；关卡里材料不够的换成 `lowAlt`，窄的替代品贴着车头一侧。
- **驾驶舱**：`helmet` 改名「驾驶舱」、`cockpit` 改名「联合驾驶舱」；`drivers` 字段；战斗里多出来的驾驶员接管其余武器组（原副驾驶逻辑）。观察镜、装弹机、测距仪、陀螺仪已迁为普通 1×1 实体，驾驶舱槽位系统删除。
- **副驾驶取消**：`SA.RETIRED` 把旧 id 换成替代品，存档读取、旧大格存档、分享码解码、蓝图、关卡 ASCII 都走它（`SA.fixCell` / `SA.fixKey` / `SA.liveId`）。
- **中炮**：`cannon_m`，2×1 横躺，开局武器；开局的车改成 1×1 驾驶舱（顶上一块甲片）+ 中炮（`SA.STARTER` 支持子格小模块 `subs`）。
- **解锁调整**：开局 = 履带、驾驶舱、锅炉、水箱、铁装甲、中炮、机枪；第一章通关加直射火炮（去掉原来的头盔驾驶舱）；第四章通关的副驾驶换成联合驾驶舱。
- **数值工具**：前五章的参考车把 2×2 驾驶舱换成 1×1 驾驶舱 + 三块甲片（联合驾驶舱第四章通关才解锁）。
- **挂件锚点**推迟到做改装挂件时再定：现在还没有用到它的地方。

### 阶段 1 · 底盘（进行中）

- **悬挂接进战斗**（完成）：`settle()` 换成悬挂姿态解算。底盘每格两个接地点，参数写在模块的 `susp` 字段里（接地点位置、上收 / 下伸行程、车身跟坡比例：履带 1、四足 0.75、双足 0.5）。车身倾角取接地点下面地面的最小二乘拟合乘以跟坡比例，车底放在平均高度但不让任何一点插地超过上收行程；被毁的底盘不参与，撞击件最多压进地面 6px。每个接地点的伸缩交给 `renderVehicle` 画。
- **履带 T1**（完成，待审查）：下段履带改成一条穿过各组负重轮底部的连续折线，跨格也连成一条（相邻格的偏移通过 `gL` / `gR` 传进来）；车尾从链轮包带底部斜下来，车头接上翘段；伸出来的减震柱画成螺旋弹簧。
- **履带滚动动画**（修复）：做货箱那次提交把更新行驶相位的代码误删了，战斗里履带链节、负重轮和腿的步态都不动；已补回，负重轮上加了一对跟着转的螺栓。
- **小模块原生画**（完成）：驾驶舱、甲片、小水罐、水罐不再借大模块精灵缩小（缩小会糊），都按 24px 原生像素画；材料角铁按模块实际大小钉。关卡里黄铜车的直射火炮换成中炮时贴着大格底边，上面压着模块就用甲片补缝。
- **新版整件底盘外观**（样机完成；用户已定进游戏，等后台把四足 4×2、真双足 2×4 的数据和规则落地后接入，见 `docs/collab.md` §5、§7）：`tools/chassis-lab.html`。
  - 大步态：脚在胯前后大幅摆动、跨过腿的轴线，步幅跟着速度变（`strideFor`）；四足机身只轻轻起伏，双足晃得多一些。
  - 测试场景（以后所有底盘视觉成果都要过一遍）：平地、土坡、陡坡、台阶、搓衣板、货箱、泥地；四足车身按四只脚拟合坡度，双足基本直立、起伏交给腿，每只脚各自伸缩够地面，页面上可以开接地点标记看悬空。
  - 四足 4×2：一整块蜘蛛甲壳 + 四条腿，后腿往后张、前腿往前张，对角两条同相大步交替，膝盖高过机身；型号「伏地蛛」「高脚蛛」（`js/legs.js` 的 `QUADS` / `quadArt`）。
  - 真双足 2×4：上两行是带陀螺仪的胯（腰挂位有模块时伸出法兰），下两行是放大约 2 倍的长腿，腿型可选六档；躯干露在外面的角切斜（`bipedArt` / `pelvis` / `torsoCuts`）。
  - 两种都用「踩实地」步态（`plantGait`）：着地时脚相对车身往后蹬的距离等于车走的距离，脚不打滑。
  - 接进游戏要等底盘数据改成整件（四足 4×2、双足 2×4），届时 `sprites.js` 直接调用这几个函数。
- **已知限制**：很长的车（6 格履带）骑在宽土包顶上时，车身是刚体，只能架在坡顶上，两端会悬空十几到几十像素（下伸行程只有 8px）。
- **四足 T1 · 伏地蛛、双足 T1 · 工装 Mk.II**（完成，待审查）：腿部光栅器和设计从 `tools/biped-lab.js` 搬到 `js/legs.js`，游戏和样机页共用；蜘蛛腿（`spiderLeg` / `carapace` / `SPIDERS`）也搬了进去。`sprites.js` 的 `BIPED_LOOK` / `QUAD_LOOK` 把外观阶段 1~3 对到腿型，T3 / T5 暂时也用 T1。
  - 蜘蛛腿往外张：同一段四足的前半格往前、后半格往后，悬挂接地点跟着脚走（`SA.suspPts`，`susp.splay` / `hips`）；精灵左边多留 16px（`LEFT`），往后张的脚不会被裁掉。
  - Mk.II 的腿静止时已经接近伸直，往下只能再伸约 3px：双足悬挂改成上收 8 / 下伸 3、车身跟坡 0.85（样机统计：四种地形悬空 > 2px 的位置 0–11%）。四足跟坡也改成 0.85。
  - 性能：腿式底盘的悬挂偏移按 2px 一档缓存。6 格四足正常过坡约 2.2ms / 帧，最坏情况（每只脚每帧都在变）约 5.8ms。
