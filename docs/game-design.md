# 蒸汽竞技场 · 游戏节奏与目标 v0.1

> 2026-09-25 · 第一阶段（材料 + 战役 + 逐步解锁 + 缴获 + 护甲）和数值自测工具已实现；地形、新模块家族、AI 性格细化排在后面

## 0. 一句话

**每一场比赛都是一道构筑题：敌人和地形出题，车间里的零件是答题工具，赢了拿到新工具。**

玩家的爽点是「看着自己的车一点点变强」：

- 格子变多：改装台从 4×3 扩到 8×6。
- 零件变多：每章解锁新模块。
- 材料变好：黄铜 → 熟铁 → 钢 → 镀镍 → 乌兹钢 → 以太合金，颜色一眼就能看出来。

## 1. 最终目标与节奏：持久战役

主线：从铁匠铺后院一路打进水晶宫，击败卫冕冠军「维多利亚女王号」。通关后开放终局「伦敦蒸汽大奖赛」赛季循环。

| 章 | 场地 | 本章考题（敌人） | 通关解锁 | 改装台 |
|---|---|---|---|---|
| 序章 | 铁匠铺后院 | 练习车 → 老汤姆的机枪车 | 第 1 场后：车间；通关：商店 | 4×3 → 5×3 |
| 一 | 后巷 | 铁皮墙（机枪打不动）、双机枪（专打没护甲的）、宿敌玛莎 | 熟铁、重装甲、四足、街头赛、银行 | 5×4 |
| 二 | 码头 | 推土机、双足撞角、双足舞者（冲撞） | 钢、铲斗 / 撞角 / 双足 | 6×4 |
| 三 | 工厂区 | 墙后高抛龟、四足齐射放风筝、黄铜公爵（侧炮） | 镀镍、高抛 / 侧炮 / 撞锤、侧挂层、改装 | 6×5 |
| 四 | 矿区 | 撞锤矿车、侧炮夜枭、铁甲圣堂（Boss 掉乌兹钢锭） | 副驾驶、委托、下注、蓝图库、友谊赛 | 7×5 |
| 五 | 水晶宫 | 差分机、宿敌玛莎复仇、女王号（掉以太结晶） | 终局锦标赛、乌兹钢锭 | 8×6 |

原则：

- **第 N 章的奖励，就是第 N+1 章的答案。** 第二章拿到撞击件和双足，正好用来撞开第三章那些躲在墙后的车。
- **章末 Boss 是检查点。** 不换构型就很难过。
- **功能按需出现。** 开局只有「出战」；车间、商店、侧挂层、蓝图库、银行、下注都跟着章节解锁。没解锁的功能完全不显示，不做灰掉的占位。
- **宿敌玛莎·布莱克**：第一章和第五章各出现一次，第五章换了更好的材料和构型，用来承载剧情。
- 已砍掉「军方收购原型机」：它会卖掉玩家的车，和「车越来越强」的主线冲突。

数据全部在 `js/content.js` 的 `SA.CAMPAIGN`，进度逻辑在 `js/camp.js`。

## 2. 材料 = 品质

| 级 | 材料 | 倍率 | 获取 | 换色 |
|---|---|---|---|---|
| 1 | 黄铜 | ×1.00 | 商店 | 原画 |
| 2 | 熟铁 | ×1.20 | 第一章后花钱升级（原价 ×0.6） | 压暗的枪铁色 |
| 3 | 钢 | ×1.45 | 第二章后（原价 ×1.0） | 蓝 |
| 4 | 镀镍 | ×1.75 | 第三章后（原价 ×1.6） | 银白 |
| 5 | 史诗 · 乌兹钢 | ×2.10 | 原价 ×2.2 + 乌兹钢锭 | 紫 |
| 6 | 传奇 · 以太合金 | ×2.50 | 原价 ×3.0 + 以太结晶 | 青 |

- **放大哪些属性**：耐久、伤害、动力、水、冷却、撞击、活塞、承重、护甲一起放大。**产热和重量不变**，所以好材料同时也更「省」。
- **怎么升级**：在车间选中车上的模块，就能升到下一级。拆下来时材料跟着模块走；库存按「模块 + 材料」分开记。
- **史诗和传奇只能靠收集**：
  - 乌兹钢锭：铁甲圣堂掉落、委托（北方矿业、马戏团）、战役通关奖励。
  - 以太结晶：女王号掉落，终局每个赛季夺冠奖励 1 块。
- **缴获**：只在战役和终局锦标赛里，赢了才能从对手剩下完好的模块里挑一件，街头赛和友谊赛不缴获。候选只有两种：
  - 你还没有的零件：车上和库存里都没有这种模块，或者只有更差的材料。
  - 史诗 / 传奇特殊件：没被打坏就一定在候选里。

  没有符合条件的，就不弹缴获。
- **价值**：修理、卖出、报废回收都按「原价 + 材料升级 + 改装」的总价值计算（`SA.cellValue`）。
- **实现**：`SA.mod(cell)` 返回按材料放大后的模块定义，属性计算和战斗都走它；换色在 `sprites.js` 的 `tintMat`，用 `color` 混合保留原图明暗，按材料缓存。

## 3. 敌人就是考题

每个敌人 = **一个明确的问题 + 一个看得见的弱点 + 一件可缴获的零件**，赛前点对手就能侦察到。

- **护甲机制**（为考题服务，同时修正了机枪全面压过火炮的问题）：
  - 装甲每挨一发先减掉固定伤害，最少保留 25%。
  - 护甲值：铁装甲 3、重装甲 6、铲斗 5、履带 2、四足 1，随材料放大。
  - 机枪一发 5 点，打装甲只冒火星，专打锅炉、水箱、驾驶舱；直射火炮一发 32 点，负责凿穿装甲。
- **AI 性格**：关卡数据里的 `style` 字段。
  - rush 冲锋：几乎一直在冲。
  - kite 放风筝：保持 400–640 的距离。
  - turtle 龟缩：守在出发点附近。
- **后续**：Boss 分阶段（女王号掉了上层以后变快），宿敌跟着玩家的进度换构型。

## 4. 地形（第二阶段）

目标：**给移动一个理由，让构筑有针对性。** 赛前公布地形，蓝图库一键换装，这样蓝图库就从收藏夹变成核心玩法。

| 元素 | 它考的是什么 |
|---|---|
| 可破坏的掩体墙 | 直射被挡住 → 用高抛、撞墙，或者绕过去 |
| 高台 / 斜坡 | 火炮 −8° 的仰角限制开始起作用；下坡冲撞有加成 |
| 场地边缘 / 坑 | 击出场外直接获胜，铲斗击退和重车有了真正的价值 |
| 泥地 / 冰面 / 铁轨 | 三种底盘各有擅长的地面 |
| 场地中间的水泵 / 煤堆 | 逼玩家离开出生点，把热量系统和地形挂钩 |

建议先做最小集：**掩体墙（工厂区）+ 场地边缘（码头）**。实现方式是高度图 y(x) 加墙体对象，弹道碰撞多一层地形判定。

## 5. 数值自测（`tools/sim.html`，已实现）

`SA.Battle.simulate()` 让两边都交给 AI，不渲染、不产生粒子，按固定步长一口气打完，每局约 5 毫秒。玩家那一侧用瞄准 0.8 的 AI 代替。

1. **战役关卡检验**：每章一台「参考玩家车」（`tools/sim.js` 的 `REF`，只用前面各章的解锁造出来）。
   - 用本章参考车打本章每一关。
   - 用上一章参考车打本章 Boss。
   - 输出胜率、平手率、平均用时和主要结局，并按合格线标颜色。
2. **对战矩阵 + 评分校准**：参考车、各章 Boss、全部战役对手、官方蓝图、我存档里的车任选。两两对打，一半局数换边，输出胜率矩阵；再按评分比分桶，看实际胜率是否单调上升。
3. **模块性价比**：按材料列出 DPS/£、耐久/£、耐久/吨、DPS/动力、DPS/吨，和同列中位数比较，标出离群值。
4. **待做：经济模拟**。让一个「贪心玩家」按章节打比赛、按性价比升级，统计每章要打几场、在哪里卡关、在哪里钱花不出去。

**第一次跑出来的结论**（每格 20 局）：

- **评分公式基本可用**：评分比 1.1–1.3 时实际胜率 64%，0.9–1.1 时 49%。
- **节奏不对**：
  - 第一章前两关比 Boss 还难（20%、5%，Boss 80%）。
  - 第三章三关全是 0–40%。
  - 第五章前两关 100%。
  - 铁甲圣堂 15%，但上一章参考车打它 0%，说明它比同章的车跳得太多。
- **性价比离群**：
  - 侧炮 DPS/£ 明显偏低。
  - 机枪 DPS/£ 仍然最高，但护甲减伤只在实战里才体现，纸面上看不出来。
5. **合格线**：

   | 指标 | 目标 |
   |---|---|
   | 平均战斗时长（总时长 100 秒） | 30–60 秒 |
   | 平局率 | < 5% |
   | 评分相同的两车 | 胜率 45%–55% |
   | 本章推荐构型打章末 Boss | 胜率 60%–70% |
   | 上一章构型打章末 Boss | 胜率 < 30% |
   | 节奏 | 每 2–3 场有一样买得起的新东西 |

目前的奖金、升级费、敌车材料都是第一版估算，等工具做出来后再调。

## 6. 暂不做

- **相邻加成 / 构型系统**：工作量和复杂度太大。
- **图纸和自定义模块**：会让系统变复杂。
- **美术细化**：材料先用简单的换色。
