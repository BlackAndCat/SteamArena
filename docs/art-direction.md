# 蒸汽竞技场 · 美术统一与辨识度方案 v0.3

> v0.3 修订（2026-09-24）：**取消角标铭牌**，辨识完全交给模块自身造型；格子提升到 48px；黄铜改为全局维多利亚装饰材质（不再是火力专属）；新增高抛火炮、撞击武器（锈钢色）；履带按一战坦克重构。下文 §2 表格已更新，§4 铭牌作废。

> 目标：**风格要统一，功能要一眼看出来**。只改表现层，组合玩法不变（格子、最多 6 层叠放、侧炮单独一层、准星瞄准的优先级都不动）。

---

## 0. 问题出在哪

以 Steamlands（Nitrome，2011）为参考，它的通病是：**所有模块都是同一种棕黄金属，明暗差不多，细节密度也差不多**。缩到手机尺寸以后，模块之间只靠 1–2 像素的细节来区分，所以一眼看不出谁是谁。

根本原因在于“统一风格”和“区分功能”用了同一套手段。比如为了统一，把所有东西都画成黄铜，结果功能也跟着分不清了。

**核心原则：两件事分开管**

| 统一靠 | 辨识靠 |
|---|---|
| 材质配方、光源、描边规则、像素尺度、细节密度 | 剪影（形状）+ 功能色（色相）+ 铭牌徽记（图标） |

在身上占主要面积的是统一的中性金属，而功能信号只用少量像素（约 15–25%），但必须是全画面独有的颜色和形状。

## 1. 读图顺序（辨识度分级）

玩家看一个模块时，依次读这 4 级信息。越靠前的越重要，必须在最远、最小的尺寸下也能读出来：

1. **剪影**：纯黑填充也能分辨出类别
2. **功能色**：一眼知道它属于哪一类（火力、能源、冷却、结构、控制）
3. **铭牌徽记**：同类里面区分具体型号（例如机枪和主炮）
4. **细节**：铆钉、管线、磨损，只用来增加质感，**不承担任何辨识任务**

> 任何一个模块，如果非要看第 4 级才能认出来，就算不合格。

## 2. 形状语言（剪影）

每一类模块有一个固定的“剪影母题”，同类内部通过大小和比例来区分。

| 类别 | 模块 | 剪影母题 | 必须有的特征 |
|---|---|---|---|
| 结构 | 装甲 | **方块**，满格，边缘平直 | 四角铆钉，边缘有 1px 倒角 |
| 火力 | 直射火炮 | **水平长管伸出格子外**（1/2 格） | 炮口制退器 + 黄铜箍 |
| 火力 | 高抛火炮 | **粗短炮管朝天 55°** | 黄铜耳轴、黑色炮口 |
| 火力 | 机枪 | **三根短管**，只伸出 1/4 格（火炮伸出 1/2 格） | 弹鼓 |
| 火力 | 侧炮 | **炮管 + 外挂支架**，挂在主体之外 | 支架的铆接臂（见 §6） |
| 能源 | 燃煤锅炉 | **方形炉体 + 大炉窗** + 烟囱 | 铁栅栏后闷燃的煤块：黑煤为主，只有块间裂缝发红（唯一发光体），不画火舌 |
| 冷却 | 水箱 | **方块水箱 + 大玻璃窗** | 水位（青色）实时下降、波纹与气泡 |
| 控制 | 驾驶舱 | **黄铜拱门剖面**，舱内空洞可见 | Q 版无性别驾驶员（大圆头、皮飞行帽、额头黄铜护目镜、蓝色连体工装+胸口齿轮徽章、黄围巾），黑描边，在拉操纵杆 |
| 移动 | 双足 | **倒三角：宽躯干 → 收腰的胯 → 一对长腿**（改版中，见 `docs/true-biped.md`） | 整车只有一对腿；胯里是黄铜陀螺仪（平衡系统）；腰挂模块切角 + 黄铜卡箍；按重心整行错位前倾 / 后仰 |
| 移动 | 四足 | **蜘蛛**：机身压低，腿往前后张开（改版中，见 `docs/true-biped.md` §4） | 膝盖必须高过机身顶板；用膝高区分型号；同样分近 / 远两层 |
| 移动 | 履带 | **一战铆接履带**：底板→上段履带→A7V 式竖肋侧框→成对负重轮→下段履带 | 尾部驱动链轮（履带绕链轮包半圈闭合）、前端上翘（Mark IV）+ 大辐条诱导轮（雷诺 FT）；底板与上方车体同色无缝；履带是一个整体，任意一段被毁 = 整条掉链（链条摊在地上、断口翘起），不画半透明虚影 |
| 撞击 | 铲斗 / 撞角 / 撞锤 | **锈钢色**，装在车头最前端 | 弧形推土板 / 锥形尖刺 / 气缸+活塞锤头 |

规则：
- **只有武器和撞击件可以伸出格子边界**，这样“突出的东西 = 会伤人的东西”。
- **只有驾驶舱是空洞剖面 + 人影**，而驾驶舱被打掉就输，所以要一眼找到它。
- **只有水箱有大面积青色**，**只有锅炉会发光**，两者不会和驾驶舱混淆。
- **底盘永远是最暗的**，压在最下面，给整台车打底。

## 3. 调色板：一套中性材质 + 语义色

### 3.1 结构
总共约 32 色，锁定为项目调色板，所有精灵只能用这些颜色。

- **中性材质（占 75–85% 的像素）**：
  - 铁 5 阶（冷灰偏蓝）→ 装甲、结构
  - 暗铁 4 阶（接近黑的蓝灰）→ 底盘、腿、履带
  - 皮革/木 3 阶 → 驾驶舱内饰、把手
- **语义色（每类只有 1 个色相，3 阶）**，一种颜色只代表一种意思：

| 语义 | 色相 | 用在哪 | 同时也用在 UI 的 |
|---|---|---|---|
| 火力 | **黄铜金** | 炮管箍、炮口环、弹链 | 攻击力数值 |
| 能源 / 热 | **炉火橙 → 红**（唯一允许发光的颜色） | 锅炉炉门、过热 | 热量条 |
| 冷却 / 水 | **青** | 水箱液位管、冷却管 | 水量条 |
| 动力 | **蒸汽白 + 压力表绿** | 管道接头、压力表 | 动力条 |
| 控制 | **舷窗玻璃（淡青白高光）** | 驾驶舱 | 驾驶舱血量 |
| UI 专用 | **洋红** | 场景中**永远不出现** | 准星锁定侧炮 |

### 3.2 起步色板
Lospec 的 steampunk 标签下，可以拿 **rusty24**、**STEAMPUKIAN 24**、**Olive Oil（15 色）** 做底，再按上面的语义表增删颜色。不要直接用原版：它们整套偏暖、偏棕，正好会重复 Steamlands 的问题。**要把中性金属往冷灰方向拉**，让暖色只留给语义色。

### 3.3 明度分层（比色相更重要）
- 背景：明度差压缩在中低段，降饱和，偏棕褐雾化。
- 载具：全明度范围。
- 发光物（炉火、炮口闪光、准星）：画面里最亮的，只有它们能碰到最高明度。
- **灰度测试**：去掉颜色后，背景、载具、发光物三层依然分得开。

## 4. ~~铭牌徽记~~（v0.3 已取消）

> 测试反馈：角标小图标只是在弥补造型不清晰。v0.3 起删除，全部改由造型表达；以下内容仅作历史记录。

维多利亚风格的“珐琅铭牌”：每个模块在**固定位置**有一块 7×7 px 的铭牌（1px 暗边 + 5×5 图标），底色取语义色，上面是 1 色的简笔图标。**主体层铭牌在左上，侧挂层铭牌在右上**，所以铭牌的位置本身就说明了模块在哪一层。

| 模块 | 图标 |
|---|---|
| 火炮 | 炮弹剖面 |
| 机枪 | 三个小点 |
| 侧炮 | 斜箭头 |
| 锅炉 | 火苗 |
| 水箱 | 水滴 |
| 装甲 | 盾 |
| 驾驶舱 | 星 |
| 底盘 | 负重轮 / 双腿 / 四腿（绿色：动力与承载） |

- 同一个图标也用在工坊按钮、商店卡片、战报里，**一个图标只有一个意思，全局通用**。
- 型号或等级用铭牌边框的**铆钉数**表示（1–3 颗），不另外造新图标。
- 铭牌是**冗余信息**：色弱玩家分不清橙和黄铜时，还能靠图标区分。

## 5. 6 层叠放的可视化

> 修订：“最高 6 层”指的是**向上叠 6 层**（含底盘行），模块必须有下方支撑；侧炮是叠在主体之上的第二个平面（侧挂层）。早先按“纵深 6 层”写的错层书脊方案作废。

叠放是这套玩法的核心，也是最容易糊成一团的地方。

### 5.1 编辑时的引导
- **承载柱**：有底盘的列画一条淡绿色竖带，提示“这一列可以往上叠”。
- **可放置角标**：选中模块后，所有合法格子的四角亮起白色角标；悬停到非法格子显示 ×，并在下方用文字说明原因（没有支撑、只能放底盘、侧炮必须挂在主体上……）。
- **被挡住的武器**：炮口画 ⊘ 标记，属性栏同步给出警告。
- **切到侧挂层时**，主体层整体压暗 55%，侧挂层保持全亮，一眼看出现在在编辑哪个平面。

### 5.2 工坊蓝图模式（切换）
- 一键切到**维多利亚蓝图**：普鲁士蓝底、白线，每个模块画成纯平的语义色块加铭牌图标。
- 锅炉周围画一圈橙色热区；侧挂层画成虚线框 + 小块铭牌；被挡住的武器，炮管线变红。
- 这种风格本身就符合时代题材，既能解决构筑时的可读性，又不用给战斗画面加 UI 噪音。赛事侦察也可以切蓝图。

## 6. 侧炮：看起来就在“另一个平面”

侧炮在规则上属于单独的一层，**画面上也必须让人感觉它在另一个平面**：

- 画一个**外挂支架**：铆接的悬臂把侧炮撑出主体轮廓，支架本身就是侧炮独有的剪影。
- 侧炮在主体上投下 **1px 硬阴影**，暗示它悬空在前面。
- 侧炮自带一圈 **1px 暗色外描边**，而主体模块在内部拼接处不描边，这样在描边规则上也和主体区分开。
- 发射时炮口火焰**画在装甲前面**，直观说明“不会被自己的装甲挡住”。
- 瞄准难、命中率低，用**准星晃动的幅度**来表达，不要只写在文字里。

## 7. 准星与高亮

| 状态 | 表现 |
|---|---|
| 弹道预览 | 每种武器一条点线（白芯黑边），终点画 ×；对准侧炮时点线变洋红 |
| 准星悬停在主体模块上 | 该模块描上 **1px 白色 + 1px 黑色双线**，在任何背景上都看得见；如果同一行前面还有模块，**实际会被打中的那块画白色虚线框**，并在底部提示“炮弹会先打中前方的铁装甲” |
| 准星悬停在侧炮上（优先） | 侧炮描**洋红**双线，同时它下面的模块**降暗 50%**，明确告诉玩家“这发只打侧炮” |
| 锁定 | 描边做蚂蚁线动画，加上铭牌图标的放大提示 |
| 被遮挡的目标 | 画成 X 光剪影（语义色、30% 透明度的平涂） |

- 准星本身用白芯加黑边，不用任何语义色，避免和场景里的颜色冲突。
- 洋红是 UI 专用色，**美术资源里禁止使用**，保证“洋红 = 侧炮锁定”这个意思不会被干扰。

## 9. 统一风格的硬规则

1. **像素尺度**：1 格 = 32×32 px（原生，v0.2 起由 16px 提升），**全游戏只能有一种像素大小**。竞技场用镜头缩放（1–1.8 倍）框住双方载具。
1. **整车感**：模块装在 28×28 的舱位里，舱位外是统一的铆接车体框架；相邻舱位的框架合并成一条铆钉支柱，**只描整车外轮廓**，内部不留背景色缝隙。模块被毁后留下烧空的舱位，框架不消失。
2. **光源**：统一从左上 45° 打光，高光在左上，阴影在右下。
3. **描边**：载具外轮廓用 1px 描边，颜色取所在材质的最暗阶（selout），不用纯黑；模块内部的拼接处不描边（侧炮除外，见 §6）。
4. **细节密度**：每 4×4 px 最多 1 个细节，铆钉只打在边缘。
5. **不做旋转缩放**：需要转向的东西预先画好多帧，禁止运行时旋转精灵，避免像素变形。
6. **不做抗锯齿**：不能和背景之间做过渡色。
7. **动画帧率**：统一 8–12 fps 的手绘节奏，UI 补间可以更平滑。

## 10. 数据层对接（玩法代码不用改）

模块注册时加一个纯表现用的字段，渲染层按这个字段自动套用色板和图标：

```js
{
  id: 'cannon_mk1',
  category: 'firepower',          // firepower | energy | cooling | structure | control | mobility
  layer: 'body',                  // body | side
  visual: { silhouette: 'barrel_long', emblem: 'shell', tier: 1 }
}
```

- 语义色**由 `category` 推导出来**，不在单个模块里单独写，这样新模块自动符合规范。
- 云存档分享的载具走同一套渲染，别人的车也一样好认。

## 11. 制作流程与验收

1. **风格锚点图**（先只做 4 个）：履带底盘、装甲、火炮、锅炉，按最终尺寸画完、定稿。之后所有资源都以它为准。
2. **铺满注册表**：按 §2 的剪影表把剩下的模块补齐。
3. **验收测试**（每个新模块都要过）：
   - 剪影测试：纯黑填充，能说出类别
   - 灰度测试：去色后三层明度依然分得开
   - 手机实机 1× 测试：5 秒内认出 6 层叠放里的每一层
   - 色盲模拟（红绿色盲）：靠铭牌能区分
   - 无标签辨识率 > 85%
4. **AI 生成**（ComfyUI）只用来做概念发散；成品精灵必须锁定调色板、手工清理，否则风格会漂。

## 12. 地形（`js/terrain-art.js`，样机 `tools/terrain-lab.html`）

地形和载具守同一套硬规则（§9）：1px 一种像素、左上 45° 光、1px 外轮廓取材质最暗阶、不抗锯齿、不旋转。场景只用中低明度（`bg` 背景色 + `leather` 木色），不抢载具。

- **土坡（矿渣堆）**：每一列从上往下依次是：1px 外轮廓（`bg[1]`）→ 受光边 → 亮层 → Bayer 有序抖动过渡 → 深层。每隔 7px 有一道跟着坡面起伏的地层虚线；和平地接缝处压暗，看起来像埋进地里。朝左上的坡和坡顶受光，朝右下的坡暗一阶，两者之间用有序抖动渐变，不留竖接缝。陡台阶露出的侧面也描边。石子（亮面在左上、影子在右下）和煤块按 4×4 格撒，一格最多一个，并在格内随机错开，避免排成点阵。
- **泥地**：一滩平的湿泥，中间最多鼓出地面 2px，大部分往地下渗。依次是：泥唇（受光亮边）→ 湿亮表面带一段段反光条纹 → 越往下越暗（有序抖动）→ 底边描边；两头 1px 台阶收窄，并往外溅几点泥。
- **木货箱**：外轮廓 `leather[0]`，木板之间 1px 板缝，每块板有受光边；边框左上亮、右下暗；斜撑是 2px 的像素台阶，下面垫 1px 影子；四角是铁包角。受损时出现裂纹，重伤时敲掉一块。碎了以后变成一地木板（碎木）。
- **坡上的车：纵向错切，不旋转**。整车切成 2px 竖条，每条按坡度整像素上下错位，车底贴合坡面，竖线保持竖直。开火后坐时车头微抬，也用同样的错切。弹道、炮口、命中判定都按同一个错切换算，画面和判定对得上。
